# LMS quick start for teachers

## Step 1: Log in to LMS

### Open the website

Select the domain for your site. The sites are:

1. Asia site (asia): [https://www.ulearning.asia/ulearning/index.html#/i18n](https://www.ulearning.asia/ulearning/index.html#/i18n)
2. Africa site (net): [https://www.ulearning.net/ulearning/index.html#/i18n](https://www.ulearning.net/ulearning/index.html#/i18n)
3. Latin America site (pro): [https://www.ulearning.pro/ulearning/index.html#/i18n](https://www.ulearning.pro/ulearning/index.html#/i18n)

![Open the LMS website](/En/Images-New/uLMS/common/1.png)

### Register/log in

If you do not have an account, register first. If you have an account, enter your account information to log in (the website currently does not support registration; contact your administrator).

![Register or log in to LMS](/En/Images-New/uLMS/common/2.png)

## Step 2: Create a course

Click the **[Create class]** button to create a course.

![Click to create a course](/En/Images-New/uLMS/quick-start-for-teachers/3.png)

Edit the course information, then create the course.

![Edit course information](/En/Images-New/uLMS/quick-start-for-teachers/4.png)

## Step 3: Set up the course menu

Open **[Settings]–[Menu management]** to configure the course menu and home page.

Enable the menus the course needs and disable those it does not. The course home page is the first page users see when they open the course.

![Set up the course menu and home page](/En/Images-New/uLMS/quick-start-for-teachers/5.png)

## Step 4: Manage course members

Manage the members related to the course: the teaching team, classes, and students. The specific operations are as follows:

- **Teaching team**: If the course is jointly managed by a teaching team, add the appropriate teachers from the school. If the course is taught individually, no action is needed.
- **Class management**: Create, edit, or delete classes, and link students and teachers to classes.
- **Student management**: Update class assignments, remove students from the class, and reset passwords.

![Manage course members](/En/Images-New/uLMS/quick-start-for-teachers/6.png)

## Step 5: Plan instruction

### Set up the course syllabus

In **[Unit]**, group different learning resources and activities according to the syllabus. You can import or create learning resources and activities.

![Set up the course syllabus](/En/Images-New/uLMS/quick-start-for-teachers/7.png)

### Set up the learning plan

Set up the learning plan in **[Courseware]**. All classes in the same course use the same courseware, but you can set different learning plans.

Courseware is imported by the course administrator. The course administrator can edit courseware and then import it into the course, or import courseware from the existing courseware library.

![Set up the courseware learning plan](/En/Images-New/uLMS/quick-start-for-teachers/8.png)

### Set up course assessment rules

Set up course assessment rules in **[Assessment]**. Scores for courseware, assignments, exams, and other activities can be counted toward the overall course score according to specified percentages. After the assessment deadline, the system automatically aggregates and calculates students' final scores.

![Set up course assessment rules](/En/Images-New/uLMS/quick-start-for-teachers/9.png)

## Step 6: Prepare before class

### Manage resources

Manage courseware, resources, question banks, exam papers, and other resources for use in the course.

![Manage course resources](/En/Images-New/uLMS/quick-start-for-teachers/10.png)

### Manage AI agents

Create personal AI agents for your own use and for direct use by teachers in the same subject and by students; link created agents to specific courses; and configure the AI assistants, AI tools, and knowledge bases associated with each course.

![Manage course AI assistants](/En/Images-New/uLMS/quick-start-for-teachers/11.png)

### Manage live sessions and classes

If the teaching process requires **[Live sessions]** or **[uClass]** classroom teaching, create them in advance. Enter the class when it is time to teach.

![Manage live sessions and classes](/En/Images-New/uLMS/quick-start-for-teachers/12.png)

### Prepare lessons

Use AI tools in **[Workbench]**, such as **[Smart lesson planning]** and **[PPT generation]**, to prepare lessons.

![Use AI tools to prepare lessons](/En/Images-New/uLMS/quick-start-for-teachers/13.png)

## Step 7: Teach the class

### Entry point

Teach through **[Classroom]–[Enter class]**.

![Enter the classroom to teach](/En/Images-New/uLMS/quick-start-for-teachers/14.png)

### Teaching

Teachers can call resources directly and use interactive tools such as roll call, Buzzer, polls, and quizzes to interact with students.

![Use classroom interactive tools](/En/Images-New/uLMS/quick-start-for-teachers/15.png)

## Step 8: After-class work

### Assess learning

Teachers can publish **[Discussion]**, **[Assignment]**, and **[Exam]** content to comprehensively assess students' learning.

![Publish a course discussion](/En/Images-New/uLMS/quick-start-for-teachers/16.png)

![Publish a course assignment](/En/Images-New/uLMS/quick-start-for-teachers/17.png)

![Publish a course exam](/En/Images-New/uLMS/quick-start-for-teachers/18.png)

### Grade assignments/exams

![Grade course assignments](/En/Images-New/uLMS/quick-start-for-teachers/19.png)

![View and grade exams](/En/Images-New/uLMS/quick-start-for-teachers/20.png)

### View teaching data

You can view teaching analytics through **[Workbench]–[AI analysis]**, **[Analysis]**, **[Classroom]–[Classroom report]**, and **[Exams]–[View grades]–[Analysis report]**.

![View course teaching data](/En/Images-New/uLMS/quick-start-for-teachers/21.png)

## Step 9: Notices and announcements

Course-related notices, announcements, and reminders are communicated to students through **[Announcements]**.

![Publish a course announcement](/En/Images-New/uLMS/quick-start-for-teachers/22.png)
