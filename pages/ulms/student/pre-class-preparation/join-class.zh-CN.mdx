# 加入班课

## 一、操作路径

**【课程列表】-【加入班课】**

![课程列表中的加入班课入口](/Images-New/uLMS/join-class/1.png)

## 二、操作步骤

### 向老师获取课程编码

老师可以通过 **【成员】-【班级】** 获取班级编码。

![老师查看班级编码](/Images-New/uLMS/join-class/2.png)

### 学生加入班课

学生可通过以下两种方式加入班课。

**方式一：通过PC端课程列表加入**

点击 **【加入班课】**，输入课程编码并确认课程信息后，即可加入班课。

![输入课程编码](/Images-New/uLMS/join-class/3.png)

![确认课程信息并加入班课](/Images-New/uLMS/join-class/4.png)

**方式二：通过优学院App扫码加入**

打开优学院App的 **【扫一扫】**，扫描课程二维码并确认课程信息后，即可加入班课。

![通过优学院App扫码加入班课](/Images-New/uLMS/join-class/5.png)
