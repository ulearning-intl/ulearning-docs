# View announcements

## 1. Navigation path

**[Course details]–[Announcements]**

![Open course announcements](/En/Images-New/uLMS/view-announcements/1.png)

## 2. Steps

### Read a new announcement

When a student opens the course details page, the system automatically displays new announcements in a pop-up. After the student clicks **[I've read it]**, the read status is synchronized with the teacher.

![Read and confirm a new announcement](/En/Images-New/uLMS/view-announcements/2.png)

### View the announcement list

Click **[Announcements]** to open the announcement list and browse all announcements. If an announcement extends beyond the display area, the system automatically collapses it. Click **[Expand]** to view the full text. After reading it, click **[Read]** in the upper-right corner to synchronize the read status with the teacher.

![View the announcement list and full text](/En/Images-New/uLMS/view-announcements/3.png)
