# Join a class

## 1. Navigation path

**[Course list]–[Join class]**

![Open Join class from the course list](/En/Images-New/uLMS/join-class/1.png)

## 2. Steps

### Get the class code from your teacher

The teacher can obtain the class code through **[Members]–[Classes]**.

![Teacher views the class code](/En/Images-New/uLMS/join-class/2.png)

### Join a class as a student

Students can join a class in either of the following ways.

**Method 1: Join from the course list on a computer**

Click **[Join class]**, enter the course code, and confirm the course information to join the class.

![Enter the course code](/En/Images-New/uLMS/join-class/3.png)

![Confirm the course information and join the class](/En/Images-New/uLMS/join-class/4.png)

**Method 2: Scan the QR code in the uLearning app**

Open **[Scan]** in the uLearning app, scan the course QR code, and confirm the course information to join the class.

![Scan the QR code in the uLearning app to join a class](/En/Images-New/uLMS/join-class/5.png)
