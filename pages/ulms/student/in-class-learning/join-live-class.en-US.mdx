# Join a live session

## 1. Navigation path

**[Course details]–[Live sessions]**

![Open course live sessions](/En/Images-New/uLMS/join-live-class/1.png)

## 2. Steps

The live-session list displays live sessions that are "In progress" or "Not started." Ended live sessions are not displayed. For a live session in progress, click **[Enter]** to join it directly.

![Join a live session from the live-session list](/En/Images-New/uLMS/join-live-class/2.png)

After entering, participate in the live session through the conferencing platform linked to your institution.

![Participate through the institution's conferencing platform](/En/Images-New/uLMS/join-live-class/3.png)
