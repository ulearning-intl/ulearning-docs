# 加入直播课

## 一、操作路径

**【课程详情】-【直播】**

![课程直播入口](/Images-New/uLMS/join-live-class/1.png)

## 二、操作步骤

直播列表展示“进行中”和“未开始”状态的直播，“已结束”的直播不会在列表中展示。对于进行中的直播，可点击 **【进入】** 直接加入。

![从直播列表进入直播课](/Images-New/uLMS/join-live-class/2.png)

进入后，根据机构关联的会议平台参加直播学习。

![通过机构会议平台参加直播](/Images-New/uLMS/join-live-class/3.png)
