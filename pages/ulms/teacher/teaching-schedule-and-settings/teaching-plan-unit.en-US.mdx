# Arrange the teaching plan (modules)

## 1. Navigation path

**[Course details]–[Modules]**

![Open course modules](/En/Images-New/uLMS/teaching-plan-unit/1.png)

## 2. Steps

A module is part of the course syllabus. In Modules, teachers can organize teaching content by week, section, project, or another structure.

Only the course administrator can create modules. Teachers for each class can publish teaching activities in modules.

### Create a module

You can create modules individually or import courseware to generate modules.

![Two ways to create a module](/En/Images-New/uLMS/teaching-plan-unit/2.png)

#### 1. Add a module

Enter a module name, select its location, and click **[Confirm]**.

![Enter module information](/En/Images-New/uLMS/teaching-plan-unit/3.png)

#### 2. Import courseware to generate modules

If a course needs to use courseware and its module structure is broadly consistent with the courseware sections, import the courseware in bulk to generate modules.

After selecting sections to import, the system creates a new module for each selected section using its name and adds the corresponding courseware as a teaching activity.

![Import courseware and generate modules](/En/Images-New/uLMS/teaching-plan-unit/4.png)

### Link teaching activities under a module

You can import or create teaching resources and activities, including courseware, resources, announcements, individual assignments, group assignments, quizzes, discussions, class sessions, live sessions, and exams.

![Link teaching activities in a module](/En/Images-New/uLMS/teaching-plan-unit/5.png)

### Teaching-activity operations

Teachers can perform operations according to the task, such as previewing courseware or grading assignments.

![Teaching-activity operations](/En/Images-New/uLMS/teaching-plan-unit/6.png)

### More module operations

Modules can be edited, moved, and deleted. Deleting a module removes its activities from the module but does not permanently delete them; they remain available in the corresponding activity modules.

![Edit, move, or delete a module](/En/Images-New/uLMS/teaching-plan-unit/7.png)
