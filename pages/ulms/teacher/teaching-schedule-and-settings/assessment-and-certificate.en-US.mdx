# Set assessment and certificates

## 1. Navigation path

**[Course details]–[Assessment]–[Set assessment rules]**

![Open course assessment rules](/En/Images-New/uLMS/assessment-and-certificate/1.png)

## 2. Steps

Teachers can set scoring items and weights in course assessment to combine formative and summative assessment. Students' online learning, assignment scores, exam scores, and classroom performance can all be included in the course assessment.

### Set rules

- **Select classes**: The classes in the assessment list are selected by default. Click to select the classes for which to set rules.
- **Set scoring-item rules**: Set item weights, calculation rules, content, assessment time, and whether students can view aggregated scores.
- **Create a scoring item**: Click **[Add custom scoring item]**.

![Set course assessment rules](/En/Images-New/uLMS/assessment-and-certificate/2.png)

### Apply rules to other classes

Click **[Apply to other classes]**, select classes, and save.

![Apply assessment rules to other classes](/En/Images-New/uLMS/assessment-and-certificate/3.png)

### Clear rules

Select classes marked "Assessment rules already exist" in the list and submit.

![Clear class assessment rules](/En/Images-New/uLMS/assessment-and-certificate/4.png)

### Export scores

Click **[Export scores]** to export a score sheet by class.

![Export scores by class](/En/Images-New/uLMS/assessment-and-certificate/5.png)

### Manage certificates

Students can receive course certificates based on their course assessment results. Teachers must set the certificate-award rules in advance.

Only the course owner can set certificate requirements and issue certificates.

#### 1. Certificate templates

Click **[My certificate templates]** to view system templates or create a template.

![View certificate templates](/En/Images-New/uLMS/assessment-and-certificate/6.png)

Click **[Create template]** to create a template and select its components. See **[Instructions]** at the bottom of the page for details, and preview the result in real time on the right.

![Create a certificate template](/En/Images-New/uLMS/assessment-and-certificate/7.png)

![Preview a certificate template in real time](/En/Images-New/uLMS/assessment-and-certificate/8.png)

#### 2. Certificate settings

When no certificate is configured, use **[Certificate settings]** to configure one. When a certificate is configured, use **[Selected certificate template]** to preview it.

![Configure and preview a course certificate](/En/Images-New/uLMS/assessment-and-certificate/9.png)

#### 3. Issue certificates

The system automatically issues certificates to students in bulk according to the certificate conditions. Certificates cannot be edited or withdrawn after they are issued.

![Issue course certificates in bulk](/En/Images-New/uLMS/assessment-and-certificate/10.png)
