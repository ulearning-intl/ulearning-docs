# Set the learning plan

## 1. Navigation path

**[Course details]–[Courseware]–[Set learning plan]**

![Open the courseware learning plan](/En/Images-New/uLMS/learning-plan/1.png)

## 2. Steps

Teachers can set a courseware learning plan for their classes and limit learning time for each section. Different classes can use different learning plans.

### Set the learning plan

- **Select a class**: Switch through the teacher and class drop-down menus and select the class for which to set a plan.
- **Set content**: Configure class learning time, hidden sections (hidden sections are not visible to students), whether exercises can be retaken, whether answers are shown after submission, and whether students can continue learning after the learning period ends.

![Set the class and section learning plan](/En/Images-New/uLMS/learning-plan/2.png)

### Reuse a learning plan

If multiple classes use the same plan, reuse the current plan through **[Apply to other classes]**.

![Apply a learning plan to other classes](/En/Images-New/uLMS/learning-plan/3.png)

### Clear a learning plan

Click **[Clear learning plan]** to clear the current plan.

![Clear a learning plan](/En/Images-New/uLMS/learning-plan/4.png)
