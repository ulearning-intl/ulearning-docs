# Manage courseware

## 1. Navigation path

**[Course details]–[Courseware]**

![Open courseware](/En/Images-New/uLMS/courseware-management/1.png)

## 2. Steps

### Create courseware in the courseware library

Enter a courseware name and click **[Create courseware]**.

![Enter a name and create courseware](/En/Images-New/uLMS/courseware-management/2.png)

You can create a section directory while creating courseware or edit it after the courseware has been created.

![Create a courseware section directory](/En/Images-New/uLMS/courseware-management/3.png)

### Manage courseware content

#### 1. Manage courseware resources

You can create videos, image documents, audio, compressed files, virtual simulation resources, and other resources, and organize them using folders.

Created resources can be used in courseware and linked repeatedly.

![Manage courseware resources](/En/Images-New/uLMS/courseware-management/4.png)

#### 2. Manage courseware questions

You can create multiple-choice, multiple-response, true/false, fill-in-the-blank, short-answer, ordering, word-selection, dropdown, cloze, comprehensive, and other question types, and organize them using folders.

Created questions can be used in courseware and linked repeatedly.

![Manage courseware questions](/En/Images-New/uLMS/courseware-management/5.png)

#### 3. Edit courseware content

Courseware is organized into sections, subsections, and pages. Pages provide templates, video, audio, document, exercise, speaking, and other components that can be called directly. Add component content from **[Resource library]** or use **[Upload locally]**, then click **[Save]** after confirming it is correct.

![Open the courseware editor](/En/Images-New/uLMS/courseware-management/6.png)

![Edit courseware content](/En/Images-New/uLMS/courseware-management/7.png)

**Copy a section link**: Click to copy the section link to the clipboard.

![Copy a courseware section link](/En/Images-New/uLMS/courseware-management/8.png)

#### 4. Collaborative editing

Link teachers who participate in collaborative courseware management to the relevant courseware.

![Set courseware collaborative editors](/En/Images-New/uLMS/courseware-management/9.png)

#### 5. Set preview sections

Click **[Set preview sections]**, select the courseware sections for preview, and save.

![Open preview-section settings](/En/Images-New/uLMS/courseware-management/10.png)

![Select courseware preview sections](/En/Images-New/uLMS/courseware-management/11.png)

#### 6. Export QR codes

Each courseware page has a corresponding QR code. Set the style and export the codes.

![Export QR codes for courseware pages](/En/Images-New/uLMS/courseware-management/12.png)

### Set courseware information

#### 1. Basic information

Complete the basic course information. Fields marked with "*" are required.

![Set basic courseware information](/En/Images-New/uLMS/courseware-management/13.png)

#### 2. Detailed introduction

On the detailed course-introduction page, enter the content introduction and syllabus. If the course has published an interactive textbook, select "Published interactive textbook" and enter the relevant publication information.

![Set the detailed courseware introduction](/En/Images-New/uLMS/courseware-management/14.png)

#### 3. Team members

The course team page displays the teacher team. You can add team members and their information on this page.

![Set courseware team members](/En/Images-New/uLMS/courseware-management/15.png)

#### 4. Portal settings

You can set the portal style. Three layouts are currently available.

![Set the courseware portal style](/En/Images-New/uLMS/courseware-management/16.png)

### Preview courseware

Click **[Preview]** on the courseware home page or in the courseware editor to preview the content.

![Preview courseware from its home page](/En/Images-New/uLMS/courseware-management/17.png)

![Preview courseware in the editor](/En/Images-New/uLMS/courseware-management/18.png)

### Publish courseware

After editing the courseware and completing the settings, publish it publicly. Select a publication site for the course.

![Publish courseware](/En/Images-New/uLMS/courseware-management/19.png)

### Update courseware

You can add or edit published course content at any time, including basic information, the course introduction, course team and portal settings, and preview-section settings. After updating the content, click **[Update course]** in the upper-right corner of the course page.

![Update published courseware](/En/Images-New/uLMS/courseware-management/20.png)

### Withdraw courseware

Students cannot study courseware after it is withdrawn.

![Withdraw courseware from the courseware library](/En/Images-New/uLMS/courseware-management/21.png)

![Withdraw courseware from its details page](/En/Images-New/uLMS/courseware-management/22.png)

### Copy courseware

Copied courseware is initially in the "Unpublished" state.

![Copy courseware](/En/Images-New/uLMS/courseware-management/23.png)

### Unlist courseware

Unlisted courseware cannot be linked to a course, but courses already linked to it are not affected and students can continue learning.

![Unlist courseware](/En/Images-New/uLMS/courseware-management/24.png)

### Delete courseware

Courseware in the "Unpublished" or "Unlisted" state can be deleted.

![Delete courseware](/En/Images-New/uLMS/courseware-management/25.png)

### Link courseware to a course

You can import existing courseware, preview courseware, switch between multiple sets of courseware, and download courseware materials.

![Link and use courseware in a course](/En/Images-New/uLMS/courseware-management/26.png)
