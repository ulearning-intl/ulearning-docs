# Manage resources

## 1. Navigation path

Path 1: **[Top of the home page]–[Resource library]** (manage all resources)

![Open the home-page resource library](/En/Images-New/uLMS/resource-management/1.png)

Path 2: **[Course details]–[Resources]** (manage resources for one course)

![Open course resources](/En/Images-New/uLMS/resource-management/2.png)

## 2. Steps

In addition to courseware, courses can publish supplementary resources such as teaching PPTs, handouts, and reference materials for students to view and download.

Teachers can upload and publish resources directly in a course, or upload them to **[Resource library]** first and then select resources from the library to publish to a course.

### Manage the personal resource library

#### 1. Create resources

Create folders to organize a type of resource, then use **[Add resource]** to upload files, folders, virtual simulation resources, links, rich content, and other resources.

![Create a folder and add resources](/En/Images-New/uLMS/resource-management/3.png)

#### 2. Rename a resource

You can change a resource name.

![Rename a resource](/En/Images-New/uLMS/resource-management/4.png)

#### 3. Edit a resource

You can change a resource name, description, and category, and set whether downloads are allowed.

![Select Edit resource](/En/Images-New/uLMS/resource-management/5.png)

![Edit resource information](/En/Images-New/uLMS/resource-management/6.png)

#### 4. Move a resource

Select the destination folder and save.

![Select Move resource](/En/Images-New/uLMS/resource-management/7.png)

![Select the resource destination](/En/Images-New/uLMS/resource-management/8.png)

#### 5. Share a resource

You can set resource access to "Only me," "Specified teachers in the organization," or "Other teachers in the organization."

![Select Share resource](/En/Images-New/uLMS/resource-management/9.png)

![Set resource-sharing permissions](/En/Images-New/uLMS/resource-management/10.png)

#### 6. Publish a resource

Select the course to which the resource should be published and save.

![Select Publish resource](/En/Images-New/uLMS/resource-management/11.png)

![Select the course for resource publication](/En/Images-New/uLMS/resource-management/12.png)

#### 7. Delete a resource

Deleted resources cannot be recovered.

![Delete a personal resource](/En/Images-New/uLMS/resource-management/13.png)

### School resources

To use a resource in **[School resources]**, first **[Copy]** it to **[My resources]**, then publish it to the relevant course.

![Copy a school resource to My resources](/En/Images-New/uLMS/resource-management/14.png)

### Course resources

#### 1. Add resources to a course

**Method 1**: Directly link a resource from **[Resource library]**.

**Method 2**: Click **[Add resource]** to create a resource in the current course. Resources created here are synchronized to **[Resource library]**.

![Link a resource from the library or create one in the course](/En/Images-New/uLMS/resource-management/15.png)

**Upload a file/virtual simulation resource**: Link **[My resources]** (personal resources in the resource library) or **[Courseware resources]**, or click **[Upload locally]** to upload directly.

![Upload a file or virtual simulation resource](/En/Images-New/uLMS/resource-management/16.png)

**Add a link/Add an image**: Edit and submit the resource according to the dialog prompts.

![Add a link or image resource](/En/Images-New/uLMS/resource-management/17.png)

#### 2. Record a micro-course

You can turn document resources into video micro-courses. Click **[Record micro-course]** to open the creation page, then click **[Record audio]** to record narration for each page. After completing all content, use **[Preview]** to check the result. You can publish it directly or close the page and continue later in **[Resource library]**.

![Select Record micro-course](/En/Images-New/uLMS/resource-management/18.png)

![Record and preview a micro-course](/En/Images-New/uLMS/resource-management/19.png)

#### 3. Send to students

Publish the resource to **[Classroom]** in the current course, select a class session, and submit.

![Select Send to students](/En/Images-New/uLMS/resource-management/20.png)

![Select the class session for resource publication](/En/Images-New/uLMS/resource-management/21.png)

#### 4. Access permissions

You can share a resource with "My classes," "All classes in the course," or a "Specified class."

![Select access-permission settings](/En/Images-New/uLMS/resource-management/22.png)

![Set course-resource access permissions](/En/Images-New/uLMS/resource-management/23.png)

#### 5. View statistics

View resource access by students in each class and use **[Remind all]** to remind students to view the resource.

![Select View statistics](/En/Images-New/uLMS/resource-management/24.png)

![View resource statistics and remind students](/En/Images-New/uLMS/resource-management/25.png)

#### 6. Other operations

- **Edit**: Change the resource name.
- **Move**: Change the resource location.
- **Delete**: Delete only the course-linked resource. Content in the resource library is not deleted. After deletion, students cannot view the resource in the course resources.

![Edit, move, or delete a course resource](/En/Images-New/uLMS/resource-management/26.png)
