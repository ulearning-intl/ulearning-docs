# Manage course members

## 1. Navigation path

**[Course details]–[Members]–[Class/Student/Teaching team management]**

## 2. Steps

Use this area to manage the classes, students, and teaching team associated with the course. Their roles and permissions are described below.

![Course member management page](/En/Images-New/uLMS/course-member-management/1.png)

### Teaching team

#### 1. Add team members

Use **[Add teacher]** to add teachers who participate in teaching this course. You do not need to add a teaching team for an individually taught course.

The associated teachers must already have been created in the administration console. If you cannot find a teacher you want to add, contact your school administrator.

![Add teaching team members](/En/Images-New/uLMS/course-member-management/2.png)

#### 2. Set teacher permissions

The course supports three permission levels: administrator, teacher, and teaching assistant. Click **[View teaching permissions]** to learn about the differences.

![Set teacher permissions](/En/Images-New/uLMS/course-member-management/3.png)

#### 3. Link or unlink classes and teachers

Use **[Assign classes]** to assign a teacher to the classes they teach. You can also use **[Remove from course]** to unlink the teacher from the classes.

![Link or unlink a teacher and classes](/En/Images-New/uLMS/course-member-management/4.png)

### Class management

#### 1. Create a class

**Method 1**: Create a class through **[Class management]–[Create class]**. To create multiple classes, enter each class name on a separate line. You can also set whether approval is required when students join or leave a class.

![Create a class and set approval rules](/En/Images-New/uLMS/course-member-management/5.png)

**Method 2**: Import classes from the student database or from another course.

![Import classes](/En/Images-New/uLMS/course-member-management/6.png)

#### 2. Edit a class

You can edit the class name and whether approval is required when students join or leave the class.

![Edit class information](/En/Images-New/uLMS/course-member-management/7.png)

#### 3. Assign teachers

Associate a teacher with a class in a course.

![Assign a teacher to a class](/En/Images-New/uLMS/course-member-management/8.png)

#### 4. Add students

Associate students with a class in a course.

![Add students to a class](/En/Images-New/uLMS/course-member-management/9.png)

#### 5. Class approval

If approval is required to join a class, review requests under **[Join/leave class requests]**.

![Review student join/leave class requests](/En/Images-New/uLMS/course-member-management/10.png)

#### 6. Delete a class

After a class is deleted, all students in it are removed from the course, and all records of their activities in the class are cleared. Proceed with caution.

![Delete a class](/En/Images-New/uLMS/course-member-management/11.png)

#### 7. Get the class code

Click the code to enlarge it. Give the code to students so they can join the class themselves.

![View the class code](/En/Images-New/uLMS/course-member-management/12.png)

### Student management

#### 1. Change a student's class

You can move a student to another existing class in the course.

![Change a student's class](/En/Images-New/uLMS/course-member-management/13.png)

#### 2. Remove a student from the course

After a student is removed from the course, their assignment, discussion, exam, and other course records are deleted.

![Remove a student from the course](/En/Images-New/uLMS/course-member-management/14.png)

#### 3. Reset a password

Teachers can reset a student's password. The reset password is a shared default password; remind the student to change it after logging in.

![Reset a student's password](/En/Images-New/uLMS/course-member-management/15.png)

#### 4. Student profile

View a student's course summary and learning, assignment, exam, and other records.

![View a student profile](/En/Images-New/uLMS/course-member-management/16.png)

#### 5. Export the roster

You can export student-list data.

![Export the student roster](/En/Images-New/uLMS/course-member-management/17.png)

### Other class-member management

#### 1. Group students

Click **[Class grouping mode]** to divide class members into groups. These groups can be used for **[Assignments]–[Group assignments]**.

![Set the class grouping mode](/En/Images-New/uLMS/course-member-management/18.png)

#### 2. Facial authentication

Facial authentication is used for student exams. After facial recognition is enabled, authentication photos must be uploaded in advance. Teachers can import photos in bulk, or students can upload their own photos.

![Manage student facial-authentication photos](/En/Images-New/uLMS/course-member-management/19.png)

**Teacher uploads student photos**: Find the relevant student and click the corresponding area to upload a photo directly. Uploaded photos are automatically approved and do not require review.

![Teacher uploads a student's authentication photo](/En/Images-New/uLMS/course-member-management/20.png)

**Review student-uploaded photos**: You can approve, reject, or replace a photo.

![Review student-uploaded authentication photos](/En/Images-New/uLMS/course-member-management/21.png)

After a photo is approved, the corresponding status is displayed on the page.

![Approved authentication-photo status](/En/Images-New/uLMS/course-member-management/22.png)
