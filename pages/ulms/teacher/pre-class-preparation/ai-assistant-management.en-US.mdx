# Manage AI assistants

## 1. Navigation path

**[Course details]–[AI workbench]–[Settings]**

![Open AI workbench settings](/En/Images-New/uLMS/ai-assistant-management/1.png)

## 2. Steps

Configure the AI assistants, AI tools, and knowledge bases associated with the course here.

![AI workbench settings page](/En/Images-New/uLMS/ai-assistant-management/2.png)

![Set AI assistants, tools, and knowledge bases](/En/Images-New/uLMS/ai-assistant-management/3.png)

### AI assistants

#### 1. Manage AI assistants

Click **[Manage my AI assistants]** to open the management page. See the uAgent documentation for details.

![Manage my AI assistants](/En/Images-New/uLMS/ai-assistant-management/4.png)

#### 2. Add an AI assistant

Use **[Add AI assistant]** to link personally created, team-created, or school-shared AI assistants to the course.

- **Method 1**: Add one from the settings page.

![Add an AI assistant in Settings](/En/Images-New/uLMS/ai-assistant-management/5.png)

![Select an AI assistant to add](/En/Images-New/uLMS/ai-assistant-management/6.png)

- **Method 2**: Add one directly through **[Select AI assistant]**.

![Select an AI assistant from the AI workbench](/En/Images-New/uLMS/ai-assistant-management/7.png)

![Confirm linking the AI assistant](/En/Images-New/uLMS/ai-assistant-management/8.png)

#### 3. Edit AI-assistant permissions

Click **[Edit settings]** to edit who can use the AI assistant.

![Edit AI-assistant settings](/En/Images-New/uLMS/ai-assistant-management/9.png)

Built-in assistants support status and user-permission settings but cannot be deleted. Assistants added by teachers support status and user-permission settings and can also be deleted.

User permissions can be set to "Teachers only," "Students only," or "Teachers and students." Choose according to the assistant's purpose.

![Set AI-assistant permissions](/En/Images-New/uLMS/ai-assistant-management/10.png)

#### 4. Delete an AI assistant

Deleting an added assistant only unlinks it from the current course. It does not delete the assistant itself, and other courses can still reuse it.

![Delete a course-linked AI assistant](/En/Images-New/uLMS/ai-assistant-management/11.png)

#### 5. Save the settings

After configuring the settings, click **[Save settings]**.

![Save AI-assistant settings](/En/Images-New/uLMS/ai-assistant-management/12.png)

### AI tools

#### 1. Edit AI-tool settings

AI tools are built-in system features. Click **[Edit settings]** to adjust their status and user permissions.

![Edit AI-tool settings](/En/Images-New/uLMS/ai-assistant-management/13.png)

Tool statuses are "Disabled" and "Enabled." When disabled, no one in the course can see or use the tool. When enabled, only users with permission can access it.

If a tool does not support detailed permissions, it is available to teachers only by default. If it supports permissions, configure the users as needed.

![Set AI-tool status and permissions](/En/Images-New/uLMS/ai-assistant-management/14.png)

#### 2. Save the settings

After configuring the settings, click **[Save settings]**.

![Save AI-tool settings](/En/Images-New/uLMS/ai-assistant-management/15.png)

### Knowledge bases

#### 1. Add a knowledge base

After linking a course knowledge base to an AI assistant, the assistant uses both the large language model and the knowledge-base content, making responses more targeted and accurate.

![Add a course knowledge base](/En/Images-New/uLMS/ai-assistant-management/16.png)

![Select a knowledge base to link](/En/Images-New/uLMS/ai-assistant-management/17.png)

#### 2. Manage knowledge bases

Click **[Manage my knowledge bases]** to open the management page. See the uAgent documentation for details.

![Manage my knowledge bases](/En/Images-New/uLMS/ai-assistant-management/18.png)

#### 3. Delete a knowledge base

Deleting an added knowledge base only unlinks it from the current course. It does not delete the knowledge base itself.

![Delete a course-linked knowledge base](/En/Images-New/uLMS/ai-assistant-management/19.png)
