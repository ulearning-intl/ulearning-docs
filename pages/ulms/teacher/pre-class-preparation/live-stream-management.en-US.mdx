# Manage live sessions

## 1. Navigation path

Path 1: **[Course details]–[Live sessions]**

![Open course live sessions](/En/Images-New/uLMS/live-stream-management/1.png)

Path 2: **[Course details]–[Classroom]–[Live sessions]**

![Open live sessions from Classroom](/En/Images-New/uLMS/live-stream-management/2.png)

## 2. Steps

### Live-session providers

The platform supports cloud conferencing, Tuoke Cloud, Polyv, WeLink, Tencent Meeting, WeLink Webinar, Miaohuidá, BigBlueButton, Microsoft Teams, and other providers. Choose one as needed.

Depending on the provider, an account may need to be linked. If required, click **[Link account]**; otherwise, skip this step.

#### 1. Link a provider

Click **[Link account]** to link a live-session account.

![Select a live-session provider to link](/En/Images-New/uLMS/live-stream-management/3.png)

![Link a live-session provider account](/En/Images-New/uLMS/live-stream-management/4.png)

#### 2. Unlink a provider

Click **[Unlink]** to remove the live-session account link.

![Unlink a live-session provider account](/En/Images-New/uLMS/live-stream-management/5.png)

#### 3. Provider does not require an account

If the "Link account" field is empty, the provider does not require an account to be linked.

![Provider that does not require a live-session account](/En/Images-New/uLMS/live-stream-management/6.png)

### Create a live session

**Method 1: Create one through [Live sessions]**

Click **[Create live session]**, enter the live-session information in the dialog, and create the session.

![Click Create live session](/En/Images-New/uLMS/live-stream-management/7.png)

![Enter live-session information](/En/Images-New/uLMS/live-stream-management/8.png)

**Method 2: Create one through [Classroom]–[Live sessions]**

![Create a live session from Classroom](/En/Images-New/uLMS/live-stream-management/9.png)

### Enter a live session

**Method 1: Enter from the [Live sessions] list**

For a live session in progress, click **[Enter]** to enter the live room and teach.

![Enter the live room from the live-session list](/En/Images-New/uLMS/live-stream-management/10.png)

**Method 2: Enter through [Classroom]–[Live-session list]**

![Enter the live room from the classroom live-session list](/En/Images-New/uLMS/live-stream-management/11.png)

### End a live session

After a live session ends, it cannot be started again or entered.

![End a live session](/En/Images-New/uLMS/live-stream-management/12.png)

### Recording being generated

If recording is enabled, a recording is generated after the live session ends. The status displays "Recording being generated."

![Live-session recording being generated](/En/Images-New/uLMS/live-stream-management/13.png)

### Delete a live session

Deleted live sessions cannot be recovered. Proceed with caution.

![Delete a live session](/En/Images-New/uLMS/live-stream-management/14.png)
