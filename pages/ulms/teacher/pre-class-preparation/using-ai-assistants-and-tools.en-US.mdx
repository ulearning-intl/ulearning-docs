# Use AI assistants and tools

## 1. Navigation path

**[Course details]–[AI workbench]**

![Open the course AI workbench](/En/Images-New/uLMS/using-ai-assistants-and-tools/1.png)

## 2. Steps

### Use AI assistants

Click the AI assistant name at the top to switch between agents. You can use the selected assistant directly in the input box or click **[Open conversation]** to have a deeper interaction in a dedicated dialog.

![Switch and use an AI assistant](/En/Images-New/uLMS/using-ai-assistants-and-tools/2.png)

### Use AI tools

The platform provides multiple AI tools that teachers can call with one click.

![Course AI-tool list](/En/Images-New/uLMS/using-ai-assistants-and-tools/3.png)

#### 1. Smart lesson planning

The smart lesson-planning tool helps teachers generate teaching-material documents. Generated documents can be edited online. Teachers can use the AI lesson-planning assistant to rewrite, expand, and optimize them. Completed materials can be downloaded, exported, saved to the resource library, or published to a class with one click.

![Use the smart lesson-planning tool](/En/Images-New/uLMS/using-ai-assistants-and-tools/4.png)

#### 2. Lesson-plan generation

The lesson-plan generation tool matches an educational level and subject to a course-module topic and uses reference materials such as a teacher-uploaded syllabus to generate a complete lesson-plan document. Generated lesson plans can also be edited online, downloaded, and exported.

![Use the lesson-plan generation tool](/En/Images-New/uLMS/using-ai-assistants-and-tools/5.png)

#### 3. Resource search

The resource-search tool searches both internal and external resources for teachers to use as supplementary teaching resources.

![Use the resource-search tool](/En/Images-New/uLMS/using-ai-assistants-and-tools/6.png)

#### 4. Smart grading

For subjective questions in assignments and exams, the smart-grading tool can score responses using custom scoring rules and generate comments. The system provides multiple scoring-rule templates for different subjects, and AI can generate a matching scoring rule from the question information.

![Use the smart-grading tool](/En/Images-New/uLMS/using-ai-assistants-and-tools/7.png)

#### 5. PPT generation

The PPT-generation tool automatically creates a presentation with a three-level outline from a topic or outline. The system provides many PPT templates to choose from.

![Use the PPT-generation tool](/En/Images-New/uLMS/using-ai-assistants-and-tools/8.png)

#### 6. Smart question generation

The smart question-generation tool creates quiz questions from knowledge points. Enter knowledge points manually or select them from an existing knowledge graph. Supported types include multiple-choice, multiple-response, true/false, fill-in-the-blank, and short-answer questions. Save generated questions to the question bank for use in quizzes and exams.

![Use the smart question-generation tool](/En/Images-New/uLMS/using-ai-assistants-and-tools/9.png)

#### 7. Video analysis

The video-analysis tool accepts video or audio uploads and generates summaries, subtitles, word clouds, and other content to help students quickly understand teaching videos.

![Use the video-analysis tool](/En/Images-New/uLMS/using-ai-assistants-and-tools/10.png)

#### 8. Document reading

The document-reading tool provides intelligent Q&A, summaries, and other functions based on documents to help students quickly read and understand teaching materials.

![Use the document-reading tool](/En/Images-New/uLMS/using-ai-assistants-and-tools/11.png)
