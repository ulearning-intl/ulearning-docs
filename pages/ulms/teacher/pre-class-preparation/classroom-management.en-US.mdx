# Manage classrooms

## 1. Navigation path

**[Course details]–[Classroom]**

![Open course classrooms](/En/Images-New/uLMS/classroom-management/1.png)

## 2. Steps

### Create a class session

**Method 1: Create one through [Classroom]–[Create class]**

Select the relevant class and create the class session.

![Click Create class](/En/Images-New/uLMS/classroom-management/2.png)

![Select the class and create a class session](/En/Images-New/uLMS/classroom-management/3.png)

After selecting **[Do not start class yet]**, the class-session status is "Not started."

![Class session in the Not started state](/En/Images-New/uLMS/classroom-management/4.png)

After selecting **[Start class]**, the class-session status is "In progress."

![Class session in the In progress state](/En/Images-New/uLMS/classroom-management/5.png)

**Method 2: Create one through [Class-session list]–[Create class]**

The process is the same as for Method 1.

![Create a class session from the class-session list](/En/Images-New/uLMS/classroom-management/6.png)

### Edit a class session

Click **[Edit]** to change the class-session name and class.

![Select Edit class session](/En/Images-New/uLMS/classroom-management/7.png)

![Edit class-session information](/En/Images-New/uLMS/classroom-management/8.png)

### Copy a class session

Click **[Copy class session]** to copy a class session. You can also copy activities such as polls and Buzzer. Copied activities are initially "Not started" and can be started directly during class.

![Copy a class session and interactive activities](/En/Images-New/uLMS/classroom-management/9.png)

### Delete a class session

Deleting a class session also deletes the classroom interactions published in it.

![Delete a class session](/En/Images-New/uLMS/classroom-management/10.png)
