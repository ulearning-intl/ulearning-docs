# Manage the question bank

## 1. Navigation path

Path 1: **[Top of the course list]–[Question bank]**

![Open the question bank from the course list](/En/Images-New/uLMS/question-bank-management/1.png)

Path 2: **[Course details]–[Exams]–[Question bank]**

![Open the question bank from course exams](/En/Images-New/uLMS/question-bank-management/2.png)

## 2. Steps

Before scheduling an exam, prepare the required questions and exam papers in **[Question bank]** and **[Exam bank]**.

### Manage question categories

#### 1. Create a folder

In **[My question bank]**, click **[Add folder]** to organize questions. Multi-level folders are supported.

![Create a question-bank folder](/En/Images-New/uLMS/question-bank-management/3.png)

#### 2. Rename a folder

Click **[Rename]** to change a folder name.

![Rename a question-bank folder](/En/Images-New/uLMS/question-bank-management/4.png)

#### 3. Move a folder

Click **[Move]** to change a folder location.

![Move a question-bank folder](/En/Images-New/uLMS/question-bank-management/5.png)

#### 4. Delete a folder

- If you select **[Keep questions and delete only the folder]**, the questions in the folder move to the root directory.
- If you select **[Delete all]**, the questions in the folder are also deleted and cannot be recovered.

![Select Delete for a question-bank folder](/En/Images-New/uLMS/question-bank-management/6.png)

![Confirm deletion of a question-bank folder](/En/Images-New/uLMS/question-bank-management/7.png)

#### 5. Bulk operations

When multiple folders are selected, you can delete or move them in bulk.

![Perform bulk operations on question-bank folders](/En/Images-New/uLMS/question-bank-management/8.png)

### Shared folders

Teaching teams can create shared folders to build and share a question bank. After entering a shared folder, create subfolders or questions inside it using the same process as for personal folders.

The sharing scope and usage permissions of every subfolder are the same as those of the root folder.

![Open a shared question-bank folder](/En/Images-New/uLMS/question-bank-management/9.png)

#### 1. Create a shared folder

Open shared folders to view those you created or help manage. Click **[Create shared folder]** to create a folder for team collaboration and sharing.

![Create a shared question-bank folder](/En/Images-New/uLMS/question-bank-management/10.png)

#### 2. Rename a shared folder

Click **[Rename]** to change a folder name.

![Rename a shared question-bank folder](/En/Images-New/uLMS/question-bank-management/11.png)

#### 3. Set shared-folder permissions

- **Usage permissions**: Choose "Only management team members" or "Available to the entire school."
- **Allow users to copy items**: When selected, other teachers can copy the question bank to their personal question bank.
- **Management team members**: The shared-folder creator can select teachers from the school to participate in collaboration.

![Set shared question-bank folder permissions](/En/Images-New/uLMS/question-bank-management/12.png)

#### 4. Delete a shared folder

After a shared folder is deleted, its subfolders and questions move back to their creators' personal directories and are not deleted along with the shared folder.

![Delete a shared question-bank folder](/En/Images-New/uLMS/question-bank-management/13.png)

### Add questions

The question bank supports manual entry, AI question generation, bulk text import, import from an exam paper, and bulk template import. Choose a method according to your needs.

Exams support 13 question types: multiple-choice, multiple-response, true/false, fill-in-the-blank, short-answer, formula calculation, ordering, word-selection, dropdown, cloze, oral reading, subjective speaking, and comprehensive questions.

#### 1. Add a question manually

Manual entry is suitable for a small number of questions. For a larger number, use bulk template or text import.

Click **[Add new question]**, select a question type, and edit the question. The example below uses a multiple-choice question; follow the page prompts for other methods.

![Select manual question entry](/En/Images-New/uLMS/question-bank-management/14.png)

Example: a multiple-choice question page.

![Create a multiple-choice question](/En/Images-New/uLMS/question-bank-management/15.png)

#### 2. Generate questions with AI

Use **[AI question generation]** to generate questions with a large language model. Enter knowledge points, select question types, number of questions, model, reference materials, and other requirements, then click **[Start generating]**.

Reference materials can include textbooks and knowledge-point explanations to improve accuracy. Other requirements can include question difficulty.

![Set AI question-generation requirements](/En/Images-New/uLMS/question-bank-management/16.png)

After questions are generated, delete individual questions you do not want. If the overall quality is poor, click **[Regenerate]**. For questions you want to keep, click **[Save to question bank]**.

![View and save AI-generated questions](/En/Images-New/uLMS/question-bank-management/17.png)

AI-generated questions saved with **[Save to question bank]** are placed in the root directory by default.

![View AI-generated questions in the question bank](/En/Images-New/uLMS/question-bank-management/18.png)

#### 3. Bulk text import

Text import is for simple text-only question types: multiple-choice, multiple-response, true/false, fill-in-the-blank, and short-answer. It does not support questions containing images, equations, video, or audio.

![Open bulk text import](/En/Images-New/uLMS/question-bank-management/19.png)

There are two ways to add questions:

**Method 1: Add by question type**

Click a question type at the top, add questions, and edit them in the template format. The left side is the editor and the right side is the preview. Use **[Bulk change scores]** to change scores for the current questions in bulk.

**Method 2: Copy existing questions**

Paste question text from a Word document into the editor. The system identifies the question types and generates the questions automatically.

![Edit and preview bulk-imported questions](/En/Images-New/uLMS/question-bank-management/20.png)

#### 4. Import from an exam paper

Use **[Import from exam paper]** to import all questions from an exam paper into the question bank for reuse or random-question exams. Select a paper and click **[Confirm]**.

![Select Import from exam paper](/En/Images-New/uLMS/question-bank-management/21.png)

![Select an exam paper to import](/En/Images-New/uLMS/question-bank-management/22.png)

Imported questions are saved in the root directory.

![View imported questions](/En/Images-New/uLMS/question-bank-management/23.png)

#### 5. Bulk template import

You can use an Excel template to import multiple questions.

![Open bulk template import](/En/Images-New/uLMS/question-bank-management/24.png)

Download the template before the first upload. Enter questions in the Excel template according to its format and requirements, then upload the file. The template supports multiple-choice, multiple-response, fill-in-the-blank, ordering, true/false, short-answer, and comprehensive questions.

![Download the question-import template](/En/Images-New/uLMS/question-bank-management/25.png)

![Upload the question-import file](/En/Images-New/uLMS/question-bank-management/26.png)

Click **[Preview]** to view how the current question appears.

![Preview a question](/En/Images-New/uLMS/question-bank-management/31.png)

### Delete a question

Click **[Delete]** to delete the current question. Deletion cannot be undone.

![Delete a question](/En/Images-New/uLMS/question-bank-management/32.png)
