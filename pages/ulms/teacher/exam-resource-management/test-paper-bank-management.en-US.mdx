# Manage the exam bank

## 1. Navigation path

Path 1: **[Top of the course list]–[Exam bank]**

![Open the exam bank from the course list](/En/Images-New/uLMS/test-paper-bank-management/1.png)

Path 2: **[Course details]–[Exams]–[Exam bank]**

![Open the exam bank from course exams](/En/Images-New/uLMS/test-paper-bank-management/2.png)

## 2. Steps

After entering questions, create exam papers. The exam system supports manual paper creation and accumulation, or copying a paper from shared exam papers for use in an exam.

### Manage exam-paper categories

#### 1. Create a folder

In **[My exam bank]**, click **[Add folder]** to organize exam papers. Multi-level folders are supported.

![Create an exam-bank folder](/En/Images-New/uLMS/test-paper-bank-management/3.png)

#### 2. Rename a folder

Click **[Rename]** to change a folder name.

![Rename an exam-bank folder](/En/Images-New/uLMS/test-paper-bank-management/4.png)

#### 3. Move a folder

Click **[Move]** to change a folder location.

![Move an exam-bank folder](/En/Images-New/uLMS/test-paper-bank-management/5.png)

#### 4. Archive a folder

Teachers can archive exam papers or folders to prevent questions from leaking before an exam. Set an archive password; users must enter the correct password to access the content.

Before archiving, bind a phone number or email address. Otherwise, the system displays a prompt. Click **[Go to link]** to complete the binding in personal information.

![Bind a phone number or email before archiving](/En/Images-New/uLMS/test-paper-bank-management/6.png)

Enter a password when archiving a file.

![Set an exam-folder archive password](/En/Images-New/uLMS/test-paper-bank-management/7.png)

#### 5. Delete a folder

- If you select **[Keep exam papers and delete only the folder]**, the papers move to the root directory.
- If you select **[Delete all]**, the papers in the folder are also deleted.

![Select Delete for an exam-bank folder](/En/Images-New/uLMS/test-paper-bank-management/8.png)

![Confirm deletion of an exam-bank folder](/En/Images-New/uLMS/test-paper-bank-management/9.png)

#### 6. Bulk operations

When multiple folders are selected, you can delete or move them in bulk.

![Perform bulk operations on exam-bank folders](/En/Images-New/uLMS/test-paper-bank-management/10.png)

### Shared folders

Teaching teams can create shared folders to build and share an exam bank. Create subfolders or papers inside a shared folder using the same process as for personal folders.

The sharing scope and usage permissions of every subfolder are the same as those of the root folder.

![Open a shared exam-paper folder](/En/Images-New/uLMS/test-paper-bank-management/11.png)

#### 1. Create a shared folder

Open shared folders to view those you created or help manage. Click **[Create shared folder]** to create a folder for team collaboration and sharing.

![Create a shared exam-paper folder](/En/Images-New/uLMS/test-paper-bank-management/12.png)

#### 2. Rename a shared folder

Click **[Rename]** to change a folder name.

![Rename a shared exam-paper folder](/En/Images-New/uLMS/test-paper-bank-management/13.png)

#### 3. Set shared-folder permissions

- **Usage permissions**: Choose "Only management team members" or "Available to the entire school."
- **Allow users to copy items**: When selected, other teachers can copy papers to their personal exam bank.
- **Management team members**: The shared-folder creator can select teachers from the school to participate in collaboration.

![Set shared exam-paper folder permissions](/En/Images-New/uLMS/test-paper-bank-management/14.png)

#### 4. Archive a shared folder

Click **[Archive]** to archive a shared folder. The process is the same as for a regular folder.

![Archive a shared exam-paper folder](/En/Images-New/uLMS/test-paper-bank-management/15.png)

#### 5. Delete a shared folder

After deletion, its subfolders and papers move back to their creators' personal directories and are not deleted along with the shared folder.

![Delete a shared exam-paper folder](/En/Images-New/uLMS/test-paper-bank-management/16.png)

### Create an exam paper

Exams support manual, automatic, and random paper creation. Manually and automatically created papers can be saved in **[My exam papers]** for later use.

![Select a paper-creation method](/En/Images-New/uLMS/test-paper-bank-management/17.png)

#### 1. Add an exam paper

Click **[Add exam paper]** to open the manual paper-creation page.

![Open manual exam-paper creation](/En/Images-New/uLMS/test-paper-bank-management/18.png)

Add and rearrange paper sections on the left. Click **[Add section]** to add one, or click a section title to switch the selected section.

![Add and switch paper sections](/En/Images-New/uLMS/test-paper-bank-management/19.png)

Use the up arrow, down arrow, or delete control to move or delete an added section.

![Move or delete a paper section](/En/Images-New/uLMS/test-paper-bank-management/20.png)

Add questions on the right. Individual addition, bulk import, and question-bank import are supported.

![Select a method for adding paper questions](/En/Images-New/uLMS/test-paper-bank-management/21.png)

- **Add individually**: Supports 13 question types, including multiple-choice, multiple-response, and true/false. Complete the fields as required.
- **Bulk import**: Supports multiple-choice, multiple-response, true/false, fill-in-the-blank, and short-answer questions. The left side is the editor and the right side is the live preview.
- **Import from question bank**: Select existing questions from a question bank and import them.

![Add paper questions individually](/En/Images-New/uLMS/test-paper-bank-management/22.png)

![Bulk-import paper questions](/En/Images-New/uLMS/test-paper-bank-management/23.png)

![Import paper questions from the question bank](/En/Images-New/uLMS/test-paper-bank-management/24.png)

After editing the paper, click **[Preview]** to view its layout and questions. Click **[Save]** to save it, or **[Save and exit]** to save and close the editor.

![Preview and save an exam paper](/En/Images-New/uLMS/test-paper-bank-management/25.png)

#### 2. Automatic paper creation

Automatic paper creation lets teachers set a paper structure and automatically select questions based on their course modules and question types.

Path: **[Exams]–[Exam bank]–[My exam papers]–[Automatic paper creation]**

![Set automatic paper creation](/En/Images-New/uLMS/test-paper-bank-management/26.png)

### Edit an exam paper

Click **[Edit]** in the paper's more-actions menu to open the edit page.

![Edit an exam paper](/En/Images-New/uLMS/test-paper-bank-management/27.png)

### Copy an exam paper

Click **[Copy]** in the target paper's more-actions menu to create a copy.

![Copy an exam paper](/En/Images-New/uLMS/test-paper-bank-management/28.png)

### Move an exam paper

Click **[Move]** in the target paper's more-actions menu to move it elsewhere.

![Move an exam paper](/En/Images-New/uLMS/test-paper-bank-management/29.png)

### Archive an exam paper

Teachers can archive papers or paper folders to prevent question leaks before an exam. Set an archive password; the correct password is required to access the content. If you forget the password, recover it through the email bound to the account.

![Archive an exam paper](/En/Images-New/uLMS/test-paper-bank-management/30.png)

### Download an exam paper

Click **[Download]** in the target paper's more-actions menu.

![Download an exam paper](/En/Images-New/uLMS/test-paper-bank-management/31.png)

### Delete an exam paper

Deleted exam papers cannot be recovered.

![Delete an exam paper](/En/Images-New/uLMS/test-paper-bank-management/32.png)
