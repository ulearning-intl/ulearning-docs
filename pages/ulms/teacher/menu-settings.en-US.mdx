# Configure the menu

## 1. Navigation path

**[Course details]–[Settings]–[Menu management]**

![Open course menu management](/En/Images-New/uLMS/menu-settings/1.png)

## 2. Steps

The course administrator can hide or enable menus and change the course home page here.

Hidden menus are invisible to all teachers and students in the course. When a menu is set as the course home page, that menu page opens by default when the course is opened on a computer.

![Set menu visibility and the course home page](/En/Images-New/uLMS/menu-settings/2.png)
