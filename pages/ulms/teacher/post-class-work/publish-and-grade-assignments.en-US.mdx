# Publish and grade assignments

## 1. Navigation path

**[Course details]–[Assignments]**

![Open course assignments](/En/Images-New/uLMS/publish-and-grade-assignments/1.png)

## 2. Steps

The platform supports three assignment types: individual assignments, group assignments, and quizzes. Course administrators can view assignments for all classes; teachers and teaching assistants can view only assignments for their own classes.

### Publish an assignment

Click **[Publish assignment]**, select individual assignment, group assignment, or quiz, and open the creation page.

![Select and publish an assignment type](/En/Images-New/uLMS/publish-and-grade-assignments/2.png)

#### 1. Individual assignment

Students can submit individual assignments by editing text online, uploading attachments, recording audio, and other methods. Teachers can set maximum score, grade display, attachment uploads, copy and paste, plagiarism checking, evaluation method, completion time, and publication classes.

Evaluation methods include teacher scoring, student peer-review, and English-writing-system scoring.

![Set an individual assignment](/En/Images-New/uLMS/publish-and-grade-assignments/3.png)

#### 2. Group assignment

A group assignment is completed and submitted collaboratively by students in groups. It is suitable for open collaborative tasks such as extracurricular research and lab reports.

Any one group member can submit. After the teacher scores the group assignment, all students in the group receive the same score.

![Set a group assignment](/En/Images-New/uLMS/publish-and-grade-assignments/4.png)

**Evaluation method**: Teacher scoring and student peer-review are supported. For student peer-review, set the weights for within-group and between-group peer-review and the number of assignments each student must review between groups. These settings cannot be changed after publication.

**Grouping mode**: Use fixed class groups or import groups. Fixed class groups are configured in advance under **[Members]–[Class grouping mode]**.

![Set group-assignment evaluation methods](/En/Images-New/uLMS/publish-and-grade-assignments/5.png)

![Set group-assignment grouping](/En/Images-New/uLMS/publish-and-grade-assignments/6.png)

#### 3. Quiz

Quizzes consist mainly of objective questions. Teachers can select questions from the question bank and insert them into a quiz.

![Create a quiz](/En/Images-New/uLMS/publish-and-grade-assignments/7.png)

![Set quiz questions](/En/Images-New/uLMS/publish-and-grade-assignments/8.png)

### Edit an assignment

Open the edit page through **[Edit]**. "Grade display type," "Evaluation method," and "Assignment time type" cannot be changed; other information can be edited.

![Edit an assignment](/En/Images-New/uLMS/publish-and-grade-assignments/9.png)

If students have submitted a quiz, only question scores can be edited. To change question content or answers, edit them in the question bank. After changing questions or scores, use **[Regrade]** on the quiz-grading page to regrade submitted students.

![Edit quiz question scores](/En/Images-New/uLMS/publish-and-grade-assignments/10.png)

![Regrade submitted quizzes](/En/Images-New/uLMS/publish-and-grade-assignments/11.png)

### Grade assignments

After an assignment is published, teachers can view, grade, and edit it. The system automatically grades objective quiz questions; teachers must grade subjective questions manually.

![Open assignment grading](/En/Images-New/uLMS/publish-and-grade-assignments/12.png)

Filter all, graded, ungraded, or unsubmitted assignments using the status filters at the top.

The list statuses and actions are:

- **Unsubmitted**: No grading action is available. Use **[Remind students to submit]** to notify students.
- **To be graded**: **[Grade]** is displayed and opens the grading page.
- **Graded**: The score and shared/revision status are displayed; view the details.

![View assignments in different student statuses](/En/Images-New/uLMS/publish-and-grade-assignments/13.png)

#### 1. Grade

The student's assignment is in the center and the student list is on the left. Click a student name to switch assignments. For an ungraded assignment, enter the score and comments on the right, optionally set sharing or revision, and submit. The system then switches to the next ungraded assignment.

- **Share**: Share the assignment with other students in the class.
- **Revision**: Require the student to rewrite the assignment.

![Grade a student assignment](/En/Images-New/uLMS/publish-and-grade-assignments/14.png)

#### 2. Regrade

Click **[Regrade]** to grade the assignment again.

![Regrade an assignment](/En/Images-New/uLMS/publish-and-grade-assignments/15.png)

#### 3. Shared assignments

Click the relevant entry to view shared assignments.

![View shared assignments](/En/Images-New/uLMS/publish-and-grade-assignments/16.png)

### Export scores

Use **[Bulk export scores]**, select classes, assignment type, and export content, and export the data.

![Bulk-export assignment scores](/En/Images-New/uLMS/publish-and-grade-assignments/17.png)

![Set assignment-score export content](/En/Images-New/uLMS/publish-and-grade-assignments/18.png)

### Delete an assignment

Deleted assignments cannot be recovered.

![Delete an assignment](/En/Images-New/uLMS/publish-and-grade-assignments/19.png)
