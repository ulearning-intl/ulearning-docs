# Manage discussions

## 1. Navigation path

**[Course details]–[Discussions]**

![Open course discussions](/En/Images-New/uLMS/discussion-management/1.png)

## 2. Steps

### Create a discussion

Teachers can publish topics and organize student discussions. Course administrators can start discussions for all classes; teachers and teaching assistants can start discussions only for their own classes.

Enter the discussion content and set the duration, participating classes, whether student posts are anonymous, whether students can see posts from other classes, minimum reply length, point rules, and other settings. Click **[Save draft]** before editing is complete, or click **[Publish]** when finished.

![Set discussion content and rules](/En/Images-New/uLMS/discussion-management/2.png)

![Save a draft or publish a discussion](/En/Images-New/uLMS/discussion-management/3.png)

### Edit a discussion

Edit a saved draft through **[More actions]–[Edit]**.

![Edit a discussion draft](/En/Images-New/uLMS/discussion-management/4.png)

### View a discussion

Click **[View details]** to open the discussion details. You can view replies, post comments, award points for comments, mark a discussion as featured, pin it, or unpin it.

![View discussion details](/En/Images-New/uLMS/discussion-management/5.png)

![Manage discussion replies and comments](/En/Images-New/uLMS/discussion-management/6.png)

### Pin a discussion

When there are many discussions, use **[Pin]** to move important discussions to the top.

![Pin an important discussion](/En/Images-New/uLMS/discussion-management/7.png)

### View the leaderboard

Use **[Leaderboard]** to view each class's number of discussion replies, number of replies received, teacher and student likes, teacher-awarded points, points, final scores, and other data. Export the table through **[Export data]**.

![View the discussion leaderboard](/En/Images-New/uLMS/discussion-management/8.png)

![Export discussion leaderboard data](/En/Images-New/uLMS/discussion-management/9.png)

### Delete a discussion

Click **[Delete]** to delete a discussion. Deletion cannot be undone.

![Delete a discussion](/En/Images-New/uLMS/discussion-management/10.png)
