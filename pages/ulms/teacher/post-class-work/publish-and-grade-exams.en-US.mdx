# Publish and grade exams

## 1. Navigation path

**[Course details]–[Exams]**

![Open course exams](/En/Images-New/uLMS/publish-and-grade-exams/1.png)

## 2. Steps

When teachers start an exam, they must schedule it and complete the related settings.

### Publish an exam

Click **[Publish exam]** to open the exam-creation page.

![Publish an exam](/En/Images-New/uLMS/publish-and-grade-exams/2.png)

Exam-creation page:

![Upper part of the exam-creation page](/En/Images-New/uLMS/publish-and-grade-exams/3.png)

![Lower part of the exam-creation page](/En/Images-New/uLMS/publish-and-grade-exams/4.png)

Exam settings:

1. **Exam name**: Enter the exam name.
2. **Assigned exam papers**: Select exam papers from the exam bank. You can select multiple papers for one exam so students randomly receive different papers to reduce cheating.
3. **Random paper creation**: The system randomly generates papers according to the paper structure and distributes them to students. It works like automatic paper creation.
4. **Passing score**: Used to calculate the exam pass rate. It cannot exceed the paper's maximum score.
5. **Answering duration**: Set how long students can answer.
6. **Number of submissions**: Set the number of attempts from 1 to 10 or unlimited. The exam result uses the highest score.
7. **Participation methods**: Set how students participate. Multiple methods can be selected. Device requirements and anti-cheating levels differ, so choose according to the exam scenario.

![Select exam participation methods](/En/Images-New/uLMS/publish-and-grade-exams/5.png)

8. **Late-arrival time**: Set how late students may be. Students cannot enter after the permitted time has passed.
9. **Submission time**: Set how long after the start students are prevented from submitting early.
10. **Exam results**: Set when and to whom results are released, or choose not to release them.
11. **Answer settings**: Configure attachments, question order, option order, watermarks, and answer order.
    - **Allow attachments for short-answer questions**: Students can select and upload files from a computer or phone. They briefly leave the exam interface during upload, creating some cheating risk; this is not recommended for strict exams.
    - **Shuffle questions**: Randomizes question order within each section, without changing section order.
    - **Shuffle options**: Randomizes options for multiple-choice and multiple-response questions.
    - **Answer watermark**: Displays the student's account information as a watermark to prevent screenshots from leaking questions.
    - **Prevent skipping questions**: Shows one question per page and requires students to answer in order.
12. **Scoring settings**: When enabled, a correctly answered multiple-response question can receive half credit.

![Set exam answer and scoring rules](/En/Images-New/uLMS/publish-and-grade-exams/6.png)

13. **Exam monitoring**: Built-in security measures help prevent cheating.
    - **Device monitoring**: Students cannot switch exam devices.
    - **IP monitoring**: Students cannot switch exam IP addresses.
    - **Screen-switch monitoring**: On phones, the system records split-screen use, background activity, app exits, and other departures from the exam interface. The teacher can set a limit; after the limit or a single duration is reached, the system submits the exam.
    - **Facial recognition**: Students must pass facial verification before entering. Authentication photos must be uploaded in advance by students and approved by teachers, or imported by teachers in bulk.
    - **Camera monitoring**: The system periodically captures photos and monitors posture, gaze deviation, leaving the seat, talking, and other behavior. Photos and abnormal behavior appear in monitoring records, and teachers can use the monitoring console to review alerts.
14. **Session scheduling**: Arrange multiple sessions so different classes can take the exam at different times. Set exam time and participating classes, or specify students, for each session.

When setting session start and end times, make the session slightly longer than the answering duration where possible.

### Edit an exam

#### 1. Edit exam information

Open the edit page through the relevant entry and edit the exam information.

![Edit exam information](/En/Images-New/uLMS/publish-and-grade-exams/7.png)

#### 2. Edit session information

Open the edit page through the relevant entry to edit **[Session scheduling]**, **[Exam-room scheduling]**, and **[Grading scheduling]**.

![Edit exam-session information](/En/Images-New/uLMS/publish-and-grade-exams/8.png)

**Session scheduling**

View all published sessions, add sessions, or edit, delete, extend answering time, or collect papers early.

- **Edit/Delete**: Change the exam time, classes, or students, or delete the session.
- **Extend answering time**: Add time when network or other objective causes make students enter late or leave insufficient answering time.
- **Collect papers early**: Force early submission if the exam ends early.

Answer records not submitted normally during the exam period are automatically submitted for students after the exam ends. Exam-room statuses are "Not started" and "In progress."

Exam session not started:

![Exam session in the Not started state](/En/Images-New/uLMS/publish-and-grade-exams/9.png)

Exam session in progress:

![Exam session in the In progress state](/En/Images-New/uLMS/publish-and-grade-exams/10.png)

**Exam-room scheduling**

For large online exams, teachers can arrange rooms according to room capacity, number of examinees, and sessions.

- **Add an exam room**: Add rooms and complete their names, seat counts, and types.

![Add an exam room](/En/Images-New/uLMS/publish-and-grade-exams/11.png)

- **Confirm exam rooms**: Select rooms for each session. Total seats must exceed the number of examinees in the session.

![Confirm rooms for an exam session](/En/Images-New/uLMS/publish-and-grade-exams/12.png)

- **Arrange exam rooms**: After confirmation, edit the room arrangement. Classes in one session can exchange rooms.

![Arrange exam rooms](/En/Images-New/uLMS/publish-and-grade-exams/13.png)

- **Proctors**: Assign or unassign proctors for different sessions.

![Assign proctors to exam sessions](/En/Images-New/uLMS/publish-and-grade-exams/14.png)

![View proctor assignments](/En/Images-New/uLMS/publish-and-grade-exams/15.png)

- **Examinee list**: Open the monitoring console for a session to view student exam status.

![View the exam examinee list](/En/Images-New/uLMS/publish-and-grade-exams/16.png)

- **Export table**: Export session, room, class or student, examinee count, and proctor information.

**Grading scheduling**

Schools can centrally arrange teacher grading after large final exams. The system automatically grades objective questions; teachers grade subjective questions. Select grading teachers and randomly or evenly distribute papers to them. After grading, view detailed grading records.

![Arrange exam graders](/En/Images-New/uLMS/publish-and-grade-exams/17.png)

### Exam monitoring

#### 1. Review facial-authentication photos

For exams with facial recognition, upload examinee authentication photos before the exam. Students can upload their own photos or teachers can upload them in bulk. Student-uploaded photos must be approved before use.

![Manage examinee facial-authentication photos](/En/Images-New/uLMS/publish-and-grade-exams/18.png)

- **Review photos**: Select a photo and choose approve, reject, or replace in the dialog.

![Review examinee facial-authentication photos](/En/Images-New/uLMS/publish-and-grade-exams/19.png)

- **Bulk review and clear**: Review or clear photos in bulk.

![Bulk-review or clear authentication photos](/En/Images-New/uLMS/publish-and-grade-exams/20.png)

- **Bulk import**: Package and upload photos according to the requirements shown on the page.

![Bulk-import examinee authentication photos](/En/Images-New/uLMS/publish-and-grade-exams/21.png)

#### 2. Exam backup code

The exam backup verification code is mainly used in two situations:

- If an examinee cannot enter because of a special situation, they can ask the teacher for the code. For example, after facial recognition is enabled, the code can be used if facial verification fails.
- A teacher outside the course team who needs to proctor can use the monitoring address shared by a course-team teacher and enter the code to open the mobile monitoring console.

![View the exam backup verification code](/En/Images-New/uLMS/publish-and-grade-exams/22.png)

#### 3. Monitor an exam

U-Test supports online proctoring. The monitoring console shows student status (entered, not entered, answering, submitted, and so on), captured photos, exam devices, abnormal-exam alerts, and other information in real time.

![Use the exam monitoring console](/En/Images-New/uLMS/publish-and-grade-exams/23.png)

### Grade an exam

After students submit, the system automatically grades objective questions. Teachers manually score subjective questions, either one paper at a time or in bulk by question.

#### 1. Grade individual papers

Path: **[Exams]–[Select an exam session]–[View scores]–[Select a student to grade]–[Grade]**

![Open individual exam grading](/En/Images-New/uLMS/publish-and-grade-exams/24.png)

Use the relevant icon to locate a subjective question, enter a score and optional comment, and click **[Finish grading]** after all questions are graded. Select **[Automatically load next]** to load the next paper automatically.

![Locate and grade subjective questions](/En/Images-New/uLMS/publish-and-grade-exams/25.png)

![Finish grading an individual paper](/En/Images-New/uLMS/publish-and-grade-exams/26.png)

#### 2. Grade in bulk

Path: **[Exams]–[Select an exam session]–[View scores]–[Bulk grading]**

- **Score one student**: Enter and save a score.
- **Bulk scoring**: Give all students awaiting grading for the current question the same score.
- **Bulk-score similar answers**: Identify answers similar to the current student's answer and score them together.

Random-question exams do not support bulk grading.

![Bulk-grade subjective exam questions](/En/Images-New/uLMS/publish-and-grade-exams/27.png)

#### 3. Regrade

After an exam starts, use regrading to update student scores together if a question answer or score is changed.

Path: **[Exams]–[Select an exam session]–[Exam scores]–[Regrade]**

![Open exam regrading](/En/Images-New/uLMS/publish-and-grade-exams/28.png)

![Confirm regrading](/En/Images-New/uLMS/publish-and-grade-exams/29.png)

### Score analysis

The exam analysis report covers basic exam information, scores, and the paper. Charts show pass rate, highest and lowest scores, exam-device distribution, score standard deviation, score ranges, item discrimination, and other indicators to help teachers analyze results.

![View exam score analysis](/En/Images-New/uLMS/publish-and-grade-exams/30.png)

Deleted exams cannot be recovered.
