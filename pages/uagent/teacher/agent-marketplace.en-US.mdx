# Agent marketplace

## 1. Navigation path

**[Log in to the agent]** -> **[Agent marketplace]**

![Open the agent marketplace](/En/Images-New/uAgent/agent-marketplace/1.png)

## 2. Steps

### 1. Agent marketplace

An institution's administrator can publish institutional agents to the agent marketplace. Teachers and students can filter agents or open and use them directly.

![Browse and filter agents](/En/Images-New/uAgent/agent-marketplace/2.png)

### 2. Application marketplace

After opening the application marketplace, you can use internal and external AI applications directly.

![Browse and use AI applications](/En/Images-New/uAgent/agent-marketplace/3.png)

### 3. Model repository

On the model-repository page, you can view introductions to integrated models and their API-calling instructions.

![View the model repository](/En/Images-New/uAgent/agent-marketplace/4.png)

### 4. My agents

**My agents** includes agents you created and agents you favorited.

You can quickly open created and favorited agents, or drag agents to change their order in the list.

![Manage My agents](/En/Images-New/uAgent/agent-marketplace/5.png)

### 5. AI capability center

Use the AI capability center to open the agent-management console directly.

![Open the AI capability center](/En/Images-New/uAgent/agent-marketplace/6.png)
