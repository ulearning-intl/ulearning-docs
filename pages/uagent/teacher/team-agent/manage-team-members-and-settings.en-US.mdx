# Manage team members and settings

## 1. Navigation path

**[Team space]** -> **[Members and settings]**

![Open the Members and settings page](/En/Images-New/uAgent/manage-team-members-and-settings/1.png)

## 2. Steps

### 1. Add members

1. Select **[Member management]** -> **[Add member]**.

   ![Add team members](/En/Images-New/uAgent/manage-team-members-and-settings/2.png)
2. Select the members to add in the dialog, and then select **[Confirm]**.

   ![Select and confirm team members](/En/Images-New/uAgent/manage-team-members-and-settings/3.png)

### 2. View permissions

1. Select **[Member management]** -> **[View permissions]**.

   ![Open member permissions](/En/Images-New/uAgent/manage-team-members-and-settings/4.png)
2. View the permission information in the dialog.

   ![View member permission information](/En/Images-New/uAgent/manage-team-members-and-settings/5.png)

### 3. View the operation log

Select **[Operation log]** to view operation details for the team space.

![View the team operation log](/En/Images-New/uAgent/manage-team-members-and-settings/6.png)

### 4. Edit the team

1. Select the **[Edit]** icon.

   ![Edit the team](/En/Images-New/uAgent/manage-team-members-and-settings/7.png)
2. Edit the relevant information in the dialog, and then select **[Confirm]**.

   ![Confirm team-information changes](/En/Images-New/uAgent/manage-team-members-and-settings/8.png)

### 5. Delete the team

1. Select **[Delete space]**.

   ![Delete the team space](/En/Images-New/uAgent/manage-team-members-and-settings/9.png)
2. Read the notice, confirm that it is correct, enter the team-space name, and then select **[Confirm]**.

   ![Confirm team-space deletion](/En/Images-New/uAgent/manage-team-members-and-settings/10.png)

### 6. Search team members

Enter the account name to find in the input field, and then select **[Search]**.

![Search team members](/En/Images-New/uAgent/manage-team-members-and-settings/11.png)
