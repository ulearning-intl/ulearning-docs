# Manage personal AI assistants

## 1. Navigation path

**[Personal space]** -> **[AI assistants]**

![Open the personal AI assistant page](/En/Images-New/uAgent/manage-personal-ai-assistant/1.png)

## 2. Steps

### 1. Create an AI assistant

1. Select **[Create AI assistant]** to create an AI assistant.
   ![Create an AI assistant](/En/Images-New/uAgent/manage-personal-ai-assistant/2.png)
2. In the **[Create AI assistant]** dialog, select manual creation or AI creation, enter the relevant information, confirm that it is correct, and then select **[Confirm]**.
   ![Enter AI-assistant information](/En/Images-New/uAgent/manage-personal-ai-assistant/3.png)

### 2. Orchestrate an AI assistant

Select **[Orchestrate]** to open the AI-assistant orchestration page.

![Open the AI-assistant orchestration page](/En/Images-New/uAgent/manage-personal-ai-assistant/4.png)

#### (1) Role settings

The orchestration page displays **[Role settings]** by default. Enter the AI assistant's basic information here.

![Set the AI assistant's role](/En/Images-New/uAgent/manage-personal-ai-assistant/5.png)

#### (2) Instructions

- Select **[Instructions]** to open the instruction-configuration page.
- Select **[Add instruction]**, enter the relevant information in the dialog, and then select **[Confirm]**.

  ![Open the instruction-configuration page](/En/Images-New/uAgent/manage-personal-ai-assistant/6.png)

  ![Add an instruction](/En/Images-New/uAgent/manage-personal-ai-assistant/7.png)

  ![Enter instruction information](/En/Images-New/uAgent/manage-personal-ai-assistant/8.png)
- Select **[Select instruction]**, choose an existing instruction, and then select **[Confirm]**. You must create an instruction before using this method.

  ![Select an existing instruction](/En/Images-New/uAgent/manage-personal-ai-assistant/9.png)

  ![Confirm the instruction selection](/En/Images-New/uAgent/manage-personal-ai-assistant/10.png)
- Select **[Group management]**, and then select **[Add group]** to create an instruction group.

  ![Open instruction-group management](/En/Images-New/uAgent/manage-personal-ai-assistant/11.png)

  ![Add an instruction group](/En/Images-New/uAgent/manage-personal-ai-assistant/12.png)

#### (3) Knowledge

1. Select **[Knowledge]** to open the knowledge-base configuration page.
   ![Open the knowledge-base configuration page](/En/Images-New/uAgent/manage-personal-ai-assistant/13.png)
2. Select **[Add knowledge base]** or **[Add knowledge base now]**.
   ![Add a knowledge base](/En/Images-New/uAgent/manage-personal-ai-assistant/14.png)
3. Select an existing knowledge base in the dialog, and then select **[Confirm]**. You must create a knowledge base before using this feature.
   ![Select an existing knowledge base](/En/Images-New/uAgent/manage-personal-ai-assistant/15.png)

#### (4) Skills

- Select **[Skills]** to open the skill-configuration page.

  ![Open the skill-configuration page](/En/Images-New/uAgent/manage-personal-ai-assistant/16.png)
- The skill plug-in supports AI question generation. Select **[AI question generation]** to enable this skill.
- Select **[Add]** to add a workflow.

  ![Enable a skill or add a workflow](/En/Images-New/uAgent/manage-personal-ai-assistant/17.png)
- Select a workflow in the dialog, and then select **[Confirm]**. Before adding a workflow plug-in, make sure that the workflow has been published and that plug-in calls are enabled.

  ![Select a workflow](/En/Images-New/uAgent/manage-personal-ai-assistant/18.png)

#### (5) Sharing

Select **[Share]**, and under **[Sharing]**, choose whether the assistant is visible only to you or shared with other teachers in your institution.

![Set the AI assistant's sharing scope](/En/Images-New/uAgent/manage-personal-ai-assistant/19.png)

#### (6) Select a large language model

Select the model switcher and choose the large language model to use.

![Select a large language model](/En/Images-New/uAgent/manage-personal-ai-assistant/20.png)

### 3. Publish an AI assistant

After completing the configuration, select **[Save and publish]**.

![Save and publish an AI assistant](/En/Images-New/uAgent/manage-personal-ai-assistant/21.png)

### 4. Preview an AI assistant

You can preview an AI assistant in either of the following ways:

- Select **[Save and preview]** on the edit page.

  ![Save and preview an AI assistant](/En/Images-New/uAgent/manage-personal-ai-assistant/22.png)
- Select **[Preview]** on the home page.

  ![Preview an AI assistant from the home page](/En/Images-New/uAgent/manage-personal-ai-assistant/23.png)

### 5. Edit an AI assistant

1. Select **[Edit]**.
   ![Edit an AI assistant](/En/Images-New/uAgent/manage-personal-ai-assistant/24.png)
2. Edit the relevant information in the dialog, confirm that it is correct, and then select **[Confirm]**.
   ![Confirm AI-assistant changes](/En/Images-New/uAgent/manage-personal-ai-assistant/25.png)

### 6. Delete an AI assistant

1. Select **[Delete]**.
   ![Delete an AI assistant](/En/Images-New/uAgent/manage-personal-ai-assistant/26.png)
2. Read the notice, confirm that it is correct, and then select **[Confirm]**.
   ![Confirm AI-assistant deletion](/En/Images-New/uAgent/manage-personal-ai-assistant/27.png)

### 7. Search AI assistants

Enter keywords, and then select **[Search]**. You must have an existing AI assistant before searching.

![Search AI assistants](/En/Images-New/uAgent/manage-personal-ai-assistant/28.png)
