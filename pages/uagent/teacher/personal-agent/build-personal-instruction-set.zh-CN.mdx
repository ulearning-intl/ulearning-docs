# 构建个人指令集

## 一、操作路径

【个人空间】→【指令集】

![进入指令集页面](/Images-New/uAgent/build-personal-instruction-set/1.png)

## 二、操作步骤

### 1. 创建指令

1. 点击【创建指令】。

   ![创建指令](/Images-New/uAgent/build-personal-instruction-set/2.png)

2. 在弹窗中填写相关信息，然后点击【确定】。

   ![填写指令信息](/Images-New/uAgent/build-personal-instruction-set/3.png)

### 2. 通过 Excel 导入

1. 点击【Excel导入】。

   ![打开 Excel 导入](/Images-New/uAgent/build-personal-instruction-set/4.png)

2. 在弹窗中选择相应操作：

   - 点击【下载Excel模板】，在本地填写指令数据。
   - 点击【上传文件】，上传已经填写完成的指令文件。

   ![下载模板或上传指令文件](/Images-New/uAgent/build-personal-instruction-set/5.png)

### 3. 分组管理

1. 点击【分组管理】。

   ![打开分组管理](/Images-New/uAgent/build-personal-instruction-set/6.png)

2. 如已有分组，点击相应分组；如没有分组，点击【添加分组】。

   ![选择或添加分组](/Images-New/uAgent/build-personal-instruction-set/7.png)

3. 在弹窗中填写相关信息，然后点击【确定】。

   ![填写分组信息](/Images-New/uAgent/build-personal-instruction-set/8.png)

### 4. 编辑指令

1. 点击【编辑】。

   ![编辑指令](/Images-New/uAgent/build-personal-instruction-set/9.png)

2. 在弹窗中修改相关信息，然后点击【确定】。

   ![确认指令修改](/Images-New/uAgent/build-personal-instruction-set/10.png)

### 5. 删除指令

1. 点击【删除】。

   ![删除指令](/Images-New/uAgent/build-personal-instruction-set/11.png)

2. 阅读提示信息并确认无误后，点击【确定】。

   ![确认删除指令](/Images-New/uAgent/build-personal-instruction-set/12.png)

### 6. 查询指令

输入关键词后点击【查询】。

![查询指令](/Images-New/uAgent/build-personal-instruction-set/13.png)
