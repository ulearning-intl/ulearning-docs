# Build a personal knowledge base

## 1. Navigation path

**[Personal space]** -> **[Knowledge bases]**

![Open the personal knowledge-base page](/En/Images-New/uAgent/build-personal-knowledge-base/1.png)

## 2. Steps

### 1. Create a knowledge base

1. Select **[Create knowledge base]**.
   ![Create a knowledge base](/En/Images-New/uAgent/build-personal-knowledge-base/2.png)
2. Enter the relevant information in the dialog, and then select **[Confirm]**.
   ![Enter knowledge-base information](/En/Images-New/uAgent/build-personal-knowledge-base/3.png)

### 2. Manage a knowledge base

Select **[Manage knowledge base]** to manage resources and question-answer pairs in the knowledge base.

![Open the knowledge-base management page](/En/Images-New/uAgent/build-personal-knowledge-base/4.png)

#### (1) Manage resources

The resource page supports adding resources, importing teaching resources, category management, and batch operations.

![Manage knowledge-base resources](/En/Images-New/uAgent/build-personal-knowledge-base/5.png)

##### Import teaching resources

1. Select **[Import teaching resources]**.
2. Select the courseware and resources to import.
3. Select **[Confirm]** to complete the import.

![Select teaching resources to import](/En/Images-New/uAgent/build-personal-knowledge-base/6.png)

![Confirm the teaching-resource import](/En/Images-New/uAgent/build-personal-knowledge-base/7.png)

##### Category management

1. Select **[Category management]**.
2. Edit knowledge-base categories or change their order in the dialog.

![Open knowledge-base category management](/En/Images-New/uAgent/build-personal-knowledge-base/8.png)

![Edit knowledge-base categories](/En/Images-New/uAgent/build-personal-knowledge-base/9.png)

##### Batch operations

After selecting one or more resources, you can set categories or delete resources in batches.

![Manage knowledge-base resources in batches](/En/Images-New/uAgent/build-personal-knowledge-base/10.png)

#### (2) Manage question-answer pairs

The question-answer-pairs page supports creating question-answer pairs, importing from Excel, and group management.

![Manage knowledge-base question-answer pairs](/En/Images-New/uAgent/build-personal-knowledge-base/11.png)

##### Method 1: Create question-answer pairs

Select **[Create question-answer pair]**, enter the relevant information in the dialog, and then select **[Confirm]**.

![Create a knowledge-base question-answer pair](/En/Images-New/uAgent/build-personal-knowledge-base/12.png)

![Enter question-answer-pair information](/En/Images-New/uAgent/build-personal-knowledge-base/13.png)

##### Method 2: Import from Excel

1. Select **[Import from Excel]**.
   ![Open Excel import for question-answer pairs](/En/Images-New/uAgent/build-personal-knowledge-base/14.png)
2. Select **[Download Excel template]**, and enter the question-answer pairs locally.
3. Select **[Upload file]** to upload a completed question-answer-pair file.
   ![Download a template or upload question-answer pairs](/En/Images-New/uAgent/build-personal-knowledge-base/15.png)

#### (3) Group management

Select **[Group management]** to add question-answer-pair groups.

![Open question-answer-pair group management](/En/Images-New/uAgent/build-personal-knowledge-base/16.png)

![Add a question-answer-pair group](/En/Images-New/uAgent/build-personal-knowledge-base/17.png)

### 3. Edit a knowledge base

1. Select **[Edit]**.
   ![Edit a knowledge base](/En/Images-New/uAgent/build-personal-knowledge-base/18.png)
2. Edit the relevant information in the dialog, and then select **[Confirm]**.
   ![Confirm knowledge-base changes](/En/Images-New/uAgent/build-personal-knowledge-base/19.png)

### 4. Delete a knowledge base

Select **[Delete]** to delete the knowledge base. A deleted knowledge base cannot be recovered, so proceed with caution.

![Delete a knowledge base](/En/Images-New/uAgent/build-personal-knowledge-base/20.png)

### 5. Search knowledge bases

Enter keywords, and then select **[Search]**.

![Search knowledge bases](/En/Images-New/uAgent/build-personal-knowledge-base/21.png)
