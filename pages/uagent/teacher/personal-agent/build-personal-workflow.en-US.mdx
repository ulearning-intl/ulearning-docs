# Build a personal workflow

## 1. Navigation path

**[Personal space]** -> **[Workflows]**

![Open the workflow page](/En/Images-New/uAgent/build-personal-workflow/1.png)

## 2. Steps

### 1. Create a workflow

1. Select **[Create workflow]**.

   ![Create a workflow](/En/Images-New/uAgent/build-personal-workflow/2.png)
2. Enter the relevant information in the dialog, and then select **[Confirm]**.

   ![Enter workflow information](/En/Images-New/uAgent/build-personal-workflow/3.png)

### 2. Orchestrate and publish a workflow

You can open the workflow-orchestration page in either of the following ways:

- Select **[Orchestrate]** for a workflow.
- Open the orchestration page directly after creating a workflow.

![Open the workflow-orchestration page](/En/Images-New/uAgent/build-personal-workflow/4.png)

After configuring the workflow on the **[Orchestrate]** page, select **[Publish]**.

![Orchestrate and publish a workflow](/En/Images-New/uAgent/build-personal-workflow/5.png)

### 3. Edit a workflow

1. Select **[Edit]**.

   ![Edit a workflow](/En/Images-New/uAgent/build-personal-workflow/6.png)
2. Edit the relevant information in the dialog, and then select **[Confirm]**.

   ![Confirm workflow changes](/En/Images-New/uAgent/build-personal-workflow/7.png)

### 4. Delete a workflow

1. Select **[Delete]**.

   ![Delete a workflow](/En/Images-New/uAgent/build-personal-workflow/8.png)
2. Read the notice, confirm that it is correct, and then select **[Confirm]**.

   ![Confirm workflow deletion](/En/Images-New/uAgent/build-personal-workflow/9.png)

### 5. Search workflows

Enter keywords, and then select **[Search]**.

![Search workflows](/En/Images-New/uAgent/build-personal-workflow/10.png)
