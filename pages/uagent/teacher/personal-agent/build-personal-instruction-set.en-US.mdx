# Build a personal instruction set

## 1. Navigation path

**[Personal space]** -> **[Instruction sets]**

![Open the instruction-set page](/En/Images-New/uAgent/build-personal-instruction-set/1.png)

## 2. Steps

### 1. Create an instruction

1. Select **[Create instruction]**.

   ![Create an instruction](/En/Images-New/uAgent/build-personal-instruction-set/2.png)
2. Enter the relevant information in the dialog, and then select **[Confirm]**.

   ![Enter instruction information](/En/Images-New/uAgent/build-personal-instruction-set/3.png)

### 2. Import from Excel

1. Select **[Import from Excel]**.

   ![Open Excel import](/En/Images-New/uAgent/build-personal-instruction-set/4.png)
2. Select the relevant action in the dialog:

   - Select **[Download Excel template]** and enter the instruction data locally.
   - Select **[Upload file]** to upload a completed instruction file.

   ![Download a template or upload an instruction file](/En/Images-New/uAgent/build-personal-instruction-set/5.png)

### 3. Manage groups

1. Select **[Group management]**.

   ![Open group management](/En/Images-New/uAgent/build-personal-instruction-set/6.png)
2. If groups already exist, select a group. If no groups exist, select **[Add group]**.

   ![Select or add a group](/En/Images-New/uAgent/build-personal-instruction-set/7.png)
3. Enter the relevant information in the dialog, and then select **[Confirm]**.

   ![Enter group information](/En/Images-New/uAgent/build-personal-instruction-set/8.png)

### 4. Edit an instruction

1. Select **[Edit]**.

   ![Edit an instruction](/En/Images-New/uAgent/build-personal-instruction-set/9.png)
2. Edit the relevant information in the dialog, and then select **[Confirm]**.

   ![Confirm instruction changes](/En/Images-New/uAgent/build-personal-instruction-set/10.png)

### 5. Delete an instruction

1. Select **[Delete]**.

   ![Delete an instruction](/En/Images-New/uAgent/build-personal-instruction-set/11.png)
2. Read the notice, confirm that it is correct, and then select **[Confirm]**.

   ![Confirm instruction deletion](/En/Images-New/uAgent/build-personal-instruction-set/12.png)

### 6. Search instructions

Enter keywords, and then select **[Search]**.

![Search instructions](/En/Images-New/uAgent/build-personal-instruction-set/13.png)
