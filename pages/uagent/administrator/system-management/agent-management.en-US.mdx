# Agent management

## Navigation path

**[System management]** - **[Agent management]**

![Agent-management navigation path](/En/Images-New/uAgent/agent-management/1.png)

## Steps

### Add an external agent

1. Select **[Add external agent]**.
   ![Add an external agent](/En/Images-New/uAgent/agent-management/2.png)
2. Enter the relevant information in the dialog, and select **[Confirm]**.
   ![Enter external-agent information](/En/Images-New/uAgent/agent-management/3.png)

### Manage agent categories

1. Select **[Category management]** to open the subpage.
   ![Open agent category management](/En/Images-New/uAgent/agent-management/4.png)
2. Select **[Add]** to add a new categorization method.
   ![Add an agent categorization method](/En/Images-New/uAgent/agent-management/5.png)

   ![Enter categorization-method information](/En/Images-New/uAgent/agent-management/6.png)
3. Select **[Add category]**, enter the category in the dialog, and select its categorization method.
   ![Add an agent category](/En/Images-New/uAgent/agent-management/7.png)

   ![Enter agent-category information](/En/Images-New/uAgent/agent-management/8.png)

### Manage an individual agent

#### (1) Pin a frequently used agent

Select the agent to manage, and select **[Pin]** in the **[Actions]** column on the far right.

![Pin a frequently used agent](/En/Images-New/uAgent/agent-management/9.png)

#### (2) Set a category

Select the agent to manage, select the triangle to the right of **[Pin]** in the **[Actions]** column, and then select **[Set category]**.

![Open agent category settings](/En/Images-New/uAgent/agent-management/10.png)

In the dialog, select the categorization method and category, and then select **[Confirm]**.

![Set an agent category](/En/Images-New/uAgent/agent-management/11.png)

#### (3) Set as default

Select the agent to manage, select the triangle to the right of **[Pin]** in the **[Actions]** column, and then select **[Set as default]**.

![Set an agent as the default](/En/Images-New/uAgent/agent-management/12.png)

#### (4) Preview an agent

Select **[Preview]** to open the agent workspace.

![Preview an agent](/En/Images-New/uAgent/agent-management/13.png)

Select **[Copy link]** or **[Share]** in the upper-right corner to share the agent in different ways.

![Share an agent](/En/Images-New/uAgent/agent-management/14.png)

#### (5) View agent usage data

Select the agent to manage, select the triangle to the right of **[Pin]** in the **[Actions]** column, and then select **[Data analytics]** to open the agent usage-data page. The page includes the number of visitors, number of conversation turns, number of words in questions and answers, and conversation details.

![View agent usage data](/En/Images-New/uAgent/agent-management/15.png)

Select a role, visitor, start date, and end date, select **[Export]**, and then select **[Export list]** or **[Export details]** to download the agent's conversation details.

![Export agent conversation details](/En/Images-New/uAgent/agent-management/16.png)
