# Application management

## Navigation path

**[System management]** - **[Application management]**

![Application-management navigation path](/En/Images-New/uAgent/application-management/1.png)

## Steps

### Filter and search applications

#### (1) Filter applications

Select the **[All applications]** and **[All]** drop-down menus to quickly filter the list by application type (internal or external), status (published or unpublished), and other conditions.

![Filter applications](/En/Images-New/uAgent/application-management/2.png)

#### (2) Search applications

Enter application-name keywords in the search box and select **[Search]** to find the target application.

![Search applications](/En/Images-New/uAgent/application-management/3.png)

### Manage internal applications

#### (1) Sort applications

Press and hold the cross-shaped cursor before an application name, and drag the application to change its position in the list. The display order on the user side stays synchronized with this order. The list order updates in real time after sorting.

![Adjust the application order](/En/Images-New/uAgent/application-management/4.png)

#### (2) Publish an application to the agent marketplace

The publication status (published or unpublished) appears to the right of each application. Select the left or right side of the blue switch to change the publication status. After publication, the application is visible to users in the institution or to marketplace users.

![Publish an application to the agent marketplace](/En/Images-New/uAgent/application-management/5.png)

### Add an external application

Select **[Add external application]** to open the configuration page.

![Add an external application](/En/Images-New/uAgent/application-management/6.png)

Follow the instructions to enter the required parameters in the dialog, such as the application name, link, cover image, and redirect method. After configuration, the external application appears in the application list and can be sorted, published, and managed in the same way as an internal application.

![Configure an external application](/En/Images-New/uAgent/application-management/7.png)
