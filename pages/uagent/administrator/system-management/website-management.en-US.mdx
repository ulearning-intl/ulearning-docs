# Website management

## Navigation path

**[System management]** - **[Website management]**

![Website-management navigation path](/En/Images-New/uAgent/website-management/1.png)

## Steps

### Change the website name

Enter the website's main title in the text box. The title appears in the browser tab and at the top of platform pages.

![Change the website name](/En/Images-New/uAgent/website-management/2.png)

### Change the browser-tab icon

Select the upload area and choose an image file that meets the requirements.

![Change the browser-tab icon](/En/Images-New/uAgent/website-management/3.png)

### Change the website logo

1. Select the upload area and choose an image file that meets the requirements.
2. After uploading, select the magnifying-glass button to preview the result. If you are not satisfied, upload a replacement.

![Change and preview the website logo](/En/Images-New/uAgent/website-management/4.png)

### Save or cancel

1. Save: After confirming that all configurations are correct, select **[Save]**. The changes take effect immediately.
2. Cancel: Select **[Cancel]** to discard unsaved changes and restore the configuration saved previously.

![Save or cancel website configuration](/En/Images-New/uAgent/website-management/5.png)
