# Model usage

## Navigation path

**[System management]** - **[Model management]**

![Model-management navigation path](/En/Images-New/uAgent/model-usage/1.png)

## Steps

### View the model-usage overview

Select **[Data dashboard]** to view the overall model-usage overview, including total usage, distribution, trends, and role proportions.

![Model-usage data dashboard](/En/Images-New/uAgent/model-usage/2.png)

#### (1) Model consumption

Select the **[All years]** drop-down menu and choose a year to view cumulative usage for the institution during the statistical period.

![View model consumption](/En/Images-New/uAgent/model-usage/3.png)

#### (2) Model-usage trends

Select the **[Day / Week / Month]** button above the trend chart to switch between usage curves at different granularities.

![View model-usage trends](/En/Images-New/uAgent/model-usage/4.png)

#### (3) Usage ranking

Select **[Start date]** and **[End date]**, and choose the relevant dates to view the usage ranking for teachers, students, and AI assistants during the selected period.

![View the model-usage ranking](/En/Images-New/uAgent/model-usage/5.png)

### Search teacher usage details

#### (1) Search and filter teachers

Enter a user's name or account in the search box, and select **[Search]** to quickly find that user's usage data.

![Search and filter teachers](/En/Images-New/uAgent/model-usage/6.png)

#### (2) Export data

Select **[Export]** to export the current search results as an Excel file for offline analysis or archiving.

![Export teacher usage details](/En/Images-New/uAgent/model-usage/7.png)

### Search student usage details

#### (1) Search and filter students

Enter a user's name or account in the search box, and select **[Search]** to quickly find that user's usage data.

![Search and filter students](/En/Images-New/uAgent/model-usage/8.png)

#### (2) Export data

Select **[Export]** to export the current search results as an Excel file for offline analysis or archiving.

![Export student usage details](/En/Images-New/uAgent/model-usage/9.png)
