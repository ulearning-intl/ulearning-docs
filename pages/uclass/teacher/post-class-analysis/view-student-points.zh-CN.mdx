# 查看学生积分

## 一、操作路径

打开 uClass，点击左侧菜单栏中的【课堂互动】。

## 二、操作步骤

### 1. 选择课堂

打开【课堂互动】并选择课程，然后在课程下方选择课堂。

![选择课程和课堂](/Images-New/uClass/view-student-points/1.png)

### 2. 打开更多工具

点击右侧工具栏中的【更多】。

![打开更多工具](/Images-New/uClass/view-student-points/2.png)

### 3. 查看积分榜

点击【积分榜】，即可查看各学生的课堂积分。

![查看学生课堂积分榜](/Images-New/uClass/view-student-points/3.png)

### 4. 查看积分详情

点击学生右侧的【查看】，即可查看该学生的积分详情。

![查看学生积分详情](/Images-New/uClass/view-student-points/4.png)
