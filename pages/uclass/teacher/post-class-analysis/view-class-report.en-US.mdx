# View the class report

## 1. Navigation path

Open uClass and select **[Classroom interaction]** in the left menu.

## 2. Steps

### 1. Select a class session

Open **[Classroom interaction]**, select a course, and then select a class session under the course.

![Select a course and class session](/En/Images-New/uClass/view-class-report/1.png)

### 2. View the class report

Select **[Class report]** in the lower-left corner to view the report for the current class session.

![Open the class report](/En/Images-New/uClass/view-class-report/2.png)

![View the class report](/En/Images-New/uClass/view-class-report/3.png)
