# 查看课堂报告

## 一、操作路径

打开 uClass，点击左侧菜单栏中的【课堂互动】。

## 二、操作步骤

### 1. 选择课堂

打开【课堂互动】并选择课程，然后在课程下方选择课堂。

![选择课程和课堂](/Images-New/uClass/view-class-report/1.png)

### 2. 查看课堂报告

点击左下方的【课堂报告】，即可查看本堂课的课堂报告。

![打开课堂报告](/Images-New/uClass/view-class-report/2.png)

![查看课堂报告内容](/Images-New/uClass/view-class-report/3.png)
