# View student points

## 1. Navigation path

Open uClass and select **[Classroom interaction]** in the left menu.

## 2. Steps

### 1. Select a class session

Open **[Classroom interaction]**, select a course, and then select a class session under the course.

![Select a course and class session](/En/Images-New/uClass/view-student-points/1.png)

### 2. Open more tools

Select **[More]** in the right toolbar.

![Open more tools](/En/Images-New/uClass/view-student-points/2.png)

### 3. View the points leaderboard

Select **[Points leaderboard]** to view each student's class points.

![View the student class-points leaderboard](/En/Images-New/uClass/view-student-points/3.png)

### 4. View points details

Select **[View]** to the right of a student to view that student's points details.

![View student points details](/En/Images-New/uClass/view-student-points/4.png)
