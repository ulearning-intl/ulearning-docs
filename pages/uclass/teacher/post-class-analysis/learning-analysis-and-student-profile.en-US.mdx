# Learning analysis and student profiles

## 1. Navigation path

Open uClass and select **[Classroom interaction]** in the left menu.

## 2. Steps

### 1. Learning analysis

#### (1) Select a class session

Open **[Classroom interaction]**, select a course, and then select a class session under the course.

![Select a course and class session](/En/Images-New/uClass/learning-analysis-and-student-profile/1.png)

#### (2) Open the AI workbench

Select **[AI workbench]**.

![Open the AI workbench](/En/Images-New/uClass/learning-analysis-and-student-profile/2.png)

#### (3) View learning analysis

Select **[Learning analysis]** to view the relevant data.

![View learning analysis](/En/Images-New/uClass/learning-analysis-and-student-profile/3.png)

#### (4) Ask AI

Use AI-powered questions to understand learning information more accurately.

![Ask AI about learning information](/En/Images-New/uClass/learning-analysis-and-student-profile/4.png)

### 2. Student profiles

#### (1) Open student profiles

Select **[Student profiles]**.

![Open student profiles](/En/Images-New/uClass/learning-analysis-and-student-profile/5.png)

#### (2) Search for a student

Enter a name or student ID to find the student's learning data and profile.

![Search student learning data and profile](/En/Images-New/uClass/learning-analysis-and-student-profile/6.png)
