# Applications

## 1. Navigation path

### Path 1: Open through uClass

Open uClass and select **[Personal space]** in the left menu.

### Path 2: Open through the website

Visit [https://app.ulearning.asia](https://app.ulearning.asia) to open the AI teaching center.

## 2. Steps

### 1. Actions in uClass

#### (1) Open frequently used applications

The frequently used applications area displays applications configured in advance by the teacher. Select an application to open it quickly.

![View and open frequently used applications](/En/Images-New/uClass/applications/1.png)

#### (2) Edit frequently used applications

To edit frequently used applications, select **[Edit]** to delete applications or drag them to change their positions.

![Enter frequently used application edit mode](/En/Images-New/uClass/applications/2.png)

![Delete applications or change their positions](/En/Images-New/uClass/applications/3.png)

#### (3) Open the application center

Select **[Application center]** to open the application-center page.

![Select Application center](/En/Images-New/uClass/applications/4.png)

![View the application center](/En/Images-New/uClass/applications/5.png)

#### (4) Set frequently used applications

Select the star in the upper-left corner of an application to control whether it appears among the frequently used applications in your personal space.

![Set frequently used applications with the star](/En/Images-New/uClass/applications/6.png)

### 2. Actions in the AI teaching center

#### (1) Log in to the AI teaching center

Visit [https://app.ulearning.asia](https://app.ulearning.asia), open the AI teaching center, and log in with the teacher account.

![Log in to the AI teaching center](/En/Images-New/uClass/applications/7.png)

#### (2) Manage my applications

Select **[Edit]** to add or delete applications under **My applications**. To add a new application to the application library, contact your institution's administrator.

![Enter My applications edit mode](/En/Images-New/uClass/applications/8.png)

![Add or delete My applications](/En/Images-New/uClass/applications/9.png)

![View the application-management result](/En/Images-New/uClass/applications/10.png)
