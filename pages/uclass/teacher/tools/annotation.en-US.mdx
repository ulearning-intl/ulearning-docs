# Annotation

## 1. Navigation path

Open the right-side menu in uClass.

## 2. Steps

### 1. Open the annotation tool

Open the right-side menu, and then select **[Annotation]**.

![Open the annotation tool](/En/Images-New/uClass/annotation/1.png)

### 2. Use the annotation tool

Select the toolbar at the bottom to switch between annotation tools.

#### Pencil

![Use the pencil tool](/En/Images-New/uClass/annotation/2.png)

#### Eraser

![Use the eraser tool](/En/Images-New/uClass/annotation/3.png)

#### Highlighter

![Use the highlighter tool](/En/Images-New/uClass/annotation/4.png)

#### Undo and redo

![Undo or redo an annotation action](/En/Images-New/uClass/annotation/5.png)

#### Share board notes

Annotations can be shared with the class with one click. Students can also scan the QR code to save the annotations.

![Share annotated board notes](/En/Images-New/uClass/annotation/6.png)

![Students scan the QR code to save annotations](/En/Images-New/uClass/annotation/7.png)
