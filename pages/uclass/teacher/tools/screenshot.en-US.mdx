# Screenshot

## 1. Navigation path

Open the right-side menu in uClass.

## 2. Steps

### 1. Open the screenshot tool

Select **[Screenshot]** in the right-side menu. The screenshot tool supports resource recommendations, Ask AI, screenshot questions, and sending screenshots to students.

![Open the screenshot tool](/En/Images-New/uClass/screenshot/1.png)

![View screenshot-tool functions](/En/Images-New/uClass/screenshot/2.png)

### 2. Resource recommendations

Select **[Resource recommendations]** to search for resources related to the image and get AI answers.

![Use resource recommendations](/En/Images-New/uClass/screenshot/3.png)

### 3. Ask AI

Select **[Ask AI]**. The AI assistant automatically answers questions based on the screenshot content.

![Use Ask AI](/En/Images-New/uClass/screenshot/4.png)

### 4. Screenshot questions

Select **[Screenshot questions]** to publish the screenshot content as a question in a classroom activity.

![Create a screenshot-question activity](/En/Images-New/uClass/screenshot/5.png)

![Publish a screenshot-question activity](/En/Images-New/uClass/screenshot/6.png)

### 5. Send to students

Select a course and class session, and then select **[Send to students]** to send the screenshot to students.

![Send the screenshot to students](/En/Images-New/uClass/screenshot/7.png)
