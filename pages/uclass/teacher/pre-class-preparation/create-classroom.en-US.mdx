# Create a class session

## 1. Navigation path

**[Classroom interaction]** -> **[Create class session]**

![Open Classroom interaction](/En/Images-New/uClass/create-classroom/1.png)

## 2. Steps

### 1. Select **[Create class session]**

![Select Create class session](/En/Images-New/uClass/create-classroom/2.png)

### 2. Enter class-session information

Enter the class-session name and select the class to create a class session.

![Enter class-session information](/En/Images-New/uClass/create-classroom/3.png)

#### (1) Start class

After you select **[Start class]**, the class-session status changes to **In progress**, and you can start teaching immediately.

![Select Start class](/En/Images-New/uClass/create-classroom/4.png)

#### (2) Do not start class yet

After you select **[Do not start class yet]**, the class-session status changes to **Upcoming**. You can prepare the class first, such as creating voting and quiz activities. When class officially starts, select **[Start class]** in the lower-right corner.

![Select Do not start class yet](/En/Images-New/uClass/create-classroom/5.png)
