# 下课/再次开课/返回课堂列表

## 一、操作路径

打开 uClass，点击左侧菜单栏中的【课堂互动】。

## 二、操作步骤

### 1. 选择课堂

打开【课堂互动】并选择课程，然后在课程下方选择课堂。

![选择课程和课堂](/Images-New/uClass/end-restart-class-and-return/1.png)

### 2. 下课

点击右下方的【下课】，结束本堂课。

![结束本堂课](/Images-New/uClass/end-restart-class-and-return/2.png)

### 3. 再次开课

点击【再次上课】，即可重新开启本堂课。

![再次开启课堂](/Images-New/uClass/end-restart-class-and-return/3.png)

### 4. 返回课堂列表

如需返回初始的课程与课堂选择界面，可点击【返回课堂列表】。

![点击返回课堂列表](/Images-New/uClass/end-restart-class-and-return/4.png)

![返回课程与课堂选择界面](/Images-New/uClass/end-restart-class-and-return/5.png)
