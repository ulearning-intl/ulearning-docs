# Start interactions (roll call, student selection, Buzzer, voting, and more)

## 1. Navigation path

Open uClass and select **[Classroom interaction]** in the left menu.

## 2. Steps

### 1. Roll call

Select **[Create roll call]** to start roll call. Roll call supports check-in with a numeric code, QR code, or one click.

To prevent students from checking in for one another, the numeric code and QR code on the large screen update automatically at intervals. Teachers can set the update interval.

![Open the roll-call tool](/En/Images-New/uClass/start-interaction/1.png)

![Create roll call](/En/Images-New/uClass/start-interaction/2.png)

#### (1) Check in with a numeric code

Students enter the numeric code shown on the screen in the app, mini program, or computer client to check in.

![Check in with a numeric code](/En/Images-New/uClass/start-interaction/3.png)

#### (2) Check in with a QR code

Students use the app or mini program to scan the QR code shown on the large screen and check in.

![Check in with a QR code](/En/Images-New/uClass/start-interaction/4.png)

#### (3) Check in with one click

Students select the check-in button in the app, mini program, or computer client to check in.

![Check in with one click](/En/Images-New/uClass/start-interaction/5.png)

### 2. Select students

During teaching, teachers can randomly select students or designate students to answer questions. If roll call has already been started for the class session, teachers can select from students who are present. Students who are absent cannot be selected.

After you select **[Randomly select students]**, the system randomly selects the specified number of students.

![Randomly select students](/En/Images-New/uClass/start-interaction/6.png)

### 3. Buzzer

Teachers can enter the Buzzer prompt in the input field. It is recommended that teachers create a draft through the computer client before class to save class time. You can also leave the field blank and explain the Buzzer question orally.

Select the number of students who can answer and then select **[Start now]**. Students can participate from their phones.

![Start a Buzzer activity](/En/Images-New/uClass/start-interaction/7.png)

### 4. Voting

Teachers can enter the voting topic and options. It is recommended that teachers create a draft through the computer client before class to save class time. You can also leave the fields blank and explain the options orally.

After you select **[Start now]**, students can vote from their phones.

![Start a voting activity](/En/Images-New/uClass/start-interaction/8.png)

### 5. Photo upload

Select **[Photo upload]** in the right-side menu, and then select the create button. Teachers can enter an activity topic and set activity points. Students receive the corresponding points after participating.

Teachers can start the activity immediately or create it before class and save it as a draft to start later. After students upload images from their phones, teachers can view the uploaded content on the large screen.

![Create a photo-upload activity](/En/Images-New/uClass/start-interaction/9.png)

![View student uploads](/En/Images-New/uClass/start-interaction/10.png)

### 6. Discussion

Select **[Discussion]** to start a classroom discussion activity.

![Open the discussion tool](/En/Images-New/uClass/start-interaction/11.png)

![Start a classroom discussion](/En/Images-New/uClass/start-interaction/12.png)

### 7. Scoring

Teachers can select students or groups to give a presentation. Other students then evaluate and score the presenters.

#### (1) Select students

Select students from the class participating in the current class session as the objects of evaluation.

#### (2) Select a group

Groups used for scoring come from the class's fixed grouping scheme. If the class has not been divided into groups, log in to the platform and go to **[Members]** -> **[Class grouping schemes]** to set up the groups.

#### (3) Other

Teachers can also define other evaluation objects. For example, after playing two films, a teacher can ask students to score the two films separately.

#### (4) Scoring details

During scoring, teachers can view the average score for each evaluation object and the number of students who participated in scoring.

![Create a classroom scoring activity](/En/Images-New/uClass/start-interaction/13.png)

![View classroom scoring details](/En/Images-New/uClass/start-interaction/14.png)

### 8. Award points

If a student participates actively in class or in another interaction organized by the teacher, the teacher can select one or more students and award points.

![Select students to award points](/En/Images-New/uClass/start-interaction/15.png)

![Complete classroom point awarding](/En/Images-New/uClass/start-interaction/16.png)

### 9. Settings

Select **[Settings]** to customize the interaction features displayed in the right toolbar.

![Open interaction settings](/En/Images-New/uClass/start-interaction/17.png)

![Set the right-side interaction tools](/En/Images-New/uClass/start-interaction/18.png)
