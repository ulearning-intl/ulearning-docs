# Notify students about class

## 1. Navigation path

Open uClass and select **[Classroom interaction]** in the left menu.

## 2. Steps

### 1. Select a class session

Open **[Classroom interaction]**, select a course, and then select a class session under the course.

![Select a course and class session](/En/Images-New/uClass/notify-students/1.png)

### 2. Send a class notification

Select **[Notify class]** to send a class notification to the students in the current class session.

![Select Notify class](/En/Images-New/uClass/notify-students/2.png)

![Result of sending the class notification](/En/Images-New/uClass/notify-students/3.png)
