# Use resources

## 1. Navigation path

Open uClass and select **[Classroom interaction]** in the left menu.

## 2. Steps

### 1. Open resources

Select **[Open resources]** in the class session.

![Open resources in the class session](/En/Images-New/uClass/use-resources/1.png)

### 2. Open resources from the toolbar

You can also select **[Resources]** in the right toolbar.

![Open resources from the right toolbar](/En/Images-New/uClass/use-resources/2.png)

### 3. Take a screenshot, annotate it, and share it

Select the resource you need for teaching, select **[Screenshot]**, annotate it, and share it with students.

![Take a screenshot of resource content](/En/Images-New/uClass/use-resources/3.png)

![Annotate and share the resource screenshot](/En/Images-New/uClass/use-resources/4.png)

### 4. Share the same screen

You can also select **[Same screen]** to share the resource content with students.

![Start sharing the resource on the same screen](/En/Images-New/uClass/use-resources/5.png)

![Share resource content with students](/En/Images-New/uClass/use-resources/6.png)
