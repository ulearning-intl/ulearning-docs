# In-class quiz

## 1. Navigation path

Open uClass and select **[Classroom interaction]** in the left menu.

## 2. Steps

### 1. Select a class session

Open **[Classroom interaction]**, select a course, and then select a class session under the course.

![Select a course and class session](/En/Images-New/uClass/in-class-quiz/1.png)

### 2. Open the quiz tool

Select **[Quiz]** in the right-side interaction-tool list.

![Open the quiz tool](/En/Images-New/uClass/in-class-quiz/2.png)

### 3. Create a quiz

Select **[Create quiz]** to start creating questions.

![Create a quiz](/En/Images-New/uClass/in-class-quiz/3.png)

### 4. Create questions manually

Enter the questions and answers in the blank fields to create the questions yourself.

![Enter questions and answers](/En/Images-New/uClass/in-class-quiz/4.png)

### 5. Import from the question bank

You can also select **[Import from question bank]** and choose questions from your personal question bank.

![Open the personal question bank](/En/Images-New/uClass/in-class-quiz/5.png)

![Select questions from the personal question bank](/En/Images-New/uClass/in-class-quiz/6.png)

### 6. Use AI question generation

Select **[AI question generation]** to generate questions with one click using AI assistance.

![Open AI question generation](/En/Images-New/uClass/in-class-quiz/7.png)

### 7. Set AI question-generation conditions

Enter the knowledge point, and select the question type, number of questions, and large language model to generate targeted questions.

![Set AI question-generation conditions](/En/Images-New/uClass/in-class-quiz/8.png)
