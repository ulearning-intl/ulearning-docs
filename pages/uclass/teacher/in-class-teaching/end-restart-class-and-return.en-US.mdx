# End class, restart class, or return to the class list

## 1. Navigation path

Open uClass and select **[Classroom interaction]** in the left menu.

## 2. Steps

### 1. Select a class session

Open **[Classroom interaction]**, select a course, and then select a class session under the course.

![Select a course and class session](/En/Images-New/uClass/end-restart-class-and-return/1.png)

### 2. End the class

Select **[End class]** in the lower-right corner to end the current class session.

![End the current class session](/En/Images-New/uClass/end-restart-class-and-return/2.png)

### 3. Restart the class

Select **[Start class again]** to restart the current class session.

![Restart the class session](/En/Images-New/uClass/end-restart-class-and-return/3.png)

### 4. Return to the class list

To return to the initial course and class-session selection screen, select **[Return to class list]**.

![Select Return to class list](/En/Images-New/uClass/end-restart-class-and-return/4.png)

![Return to the course and class-session selection screen](/En/Images-New/uClass/end-restart-class-and-return/5.png)
