# Software download

## 1. Navigation path

### Path 1: Open the Download Center through the uLearning website

Open the uLearning website and select **[Download Center]** to open the Download Center.

- Asia-Pacific site: [https://www.ulearning.asia/ulearning/index.html#/i18n](https://www.ulearning.asia/ulearning/index.html#/i18n)
- Africa site: [https://www.ulearning.net/ulearning/index.html#/i18n](https://www.ulearning.net/ulearning/index.html#/i18n)
- Latin America site: [https://www.ulearning.pro/ulearning/index.html#/i18n](https://www.ulearning.pro/ulearning/index.html#/i18n)

![Open the Download Center through the uLearning website](/En/Images-New/uClass/software-download/1.png)

### Path 2: Open the Download Center directly

- Asia-Pacific site: [https://www.ulearning.asia/udownload/](https://www.ulearning.asia/udownload/)
- Africa site: [https://www.ulearning.net/udownload/](https://www.ulearning.net/udownload/)
- Latin America site: [https://www.ulearning.pro/udownload/](https://www.ulearning.pro/udownload/)

## 2. Steps

### 1. Open the uLearning website

Open a browser, enter the URL for the relevant site, and open the uLearning website.

### 2. Open the Download Center

Select **[Download Center]** to open the Download Center.

![Open the Download Center](/En/Images-New/uClass/software-download/2.png)

### 3. Download uClass 3.0

Scroll down to find uClass 3.0 and select the download option. Windows is currently the only supported system.

![Download uClass 3.0](/En/Images-New/uClass/software-download/3.png)

### 4. Install uClass

Select an installation location and select **[Quick install]**.

![Select an installation location and install quickly](/En/Images-New/uClass/software-download/4.png)
