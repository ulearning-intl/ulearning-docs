# Software information and version

## 1. Navigation path

**[More]** -> **[Settings]** -> **[Version information]**

## 2. Steps

### 1. Open settings

Open the right-side menu, select **[More]**, and then select **[Settings]**.

![Open the right-side menu and select More](/En/Images-New/uClass/software-information-and-version/1.png)

![Open settings](/En/Images-New/uClass/software-information-and-version/2.png)

### 2. View version information

Select **[Version information]** to view the current version. To download the latest version, select **[Company website]** to open the download page.

![View current version information](/En/Images-New/uClass/software-information-and-version/3.png)

### 3. Check for updates

To check whether the current version is the latest, select **[Check for updates]**, and then select **[Check again]** to check whether an update is needed.

![Check for version updates again](/En/Images-New/uClass/software-information-and-version/4.png)
