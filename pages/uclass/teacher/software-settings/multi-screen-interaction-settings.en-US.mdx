# Multi-screen interaction settings

## 1. Navigation path

**[More]** -> **[Settings]** -> **[Multi-screen interaction]**

## 2. Steps

### 1. Open settings

Open the right-side menu, select **[More]**, and then select **[Settings]**.

![Open the right-side menu and select More](/En/Images-New/uClass/multi-screen-interaction-settings/1.png)

![Open settings](/En/Images-New/uClass/multi-screen-interaction-settings/2.png)

### 2. Activate multi-screen interaction

Enter the activation code for the multi-screen interaction feature. If you do not have an activation code, contact your institution's administrator.

![Enter the multi-screen interaction activation code](/En/Images-New/uClass/multi-screen-interaction-settings/3.png)
