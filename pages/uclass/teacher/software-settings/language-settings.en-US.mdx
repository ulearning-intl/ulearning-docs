# Language settings

## 1. Navigation path

**[More]** -> **[Settings]** -> **[Language settings]**

## 2. Steps

### 1. Open settings

Open the right-side menu, select **[More]**, and then select **[Settings]**.

![Open the right-side menu and select More](/En/Images-New/uClass/language-settings/1.png)

![Open settings](/En/Images-New/uClass/language-settings/2.png)

### 2. Select a language

Select **[Language settings]** to switch to the required language.

uClass supports Simplified Chinese, Traditional Chinese, English, Russian, French, Arabic, Spanish, Portuguese, Indonesian, and Thai, for a total of 10 languages.

![Select a language](/En/Images-New/uClass/language-settings/3.png)
