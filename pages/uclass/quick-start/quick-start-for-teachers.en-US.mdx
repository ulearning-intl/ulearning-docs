# uClass quick start for teachers

## Step 1: Download the uClass client

### Open the website

Select the domain for your region. Available sites:

- Asia-Pacific site: [https://www.ulearning.asia/ulearning/index.html#/i18n](https://www.ulearning.asia/ulearning/index.html#/i18n)
- Africa site: [https://www.ulearning.net/ulearning/index.html#/i18n](https://www.ulearning.net/ulearning/index.html#/i18n)
- Latin America site: [https://www.ulearning.pro/ulearning/index.html#/i18n](https://www.ulearning.pro/ulearning/index.html#/i18n)

![Open the uClass download website](/En/Images-New/uClass/quick-start-for-teachers/1.png)

### Select the installer for your site

Select the appropriate site in the upper-right corner, then select the **[Windows]** icon to start the download. The uClass client currently supports Windows only.

![Select a site and download the Windows installer](/En/Images-New/uClass/quick-start-for-teachers/2.png)

## Step 2: Log in

Select **[Log in]** in the right-side menu, enter the teacher account credentials, and then select **[Log in]**.

![Log in to the teacher account](/En/Images-New/uClass/quick-start-for-teachers/3.png)

## Step 3: Quickly create or join a class session

### 1. Create a class session

Select **[Classroom interaction]**, and then select **[Create class session]**.

![Create a class session](/En/Images-New/uClass/quick-start-for-teachers/4.png)

### 2. Join an existing class session

If a class session already exists, select it to join quickly.

![Join an existing class session](/En/Images-New/uClass/quick-start-for-teachers/5.png)

## Step 4: Activate the subject whiteboard (if needed)

### 1. Open settings

Select **[More]**, and then select **[Settings]**.

![Open settings](/En/Images-New/uClass/quick-start-for-teachers/6.png)

### 2. Activate the subject whiteboard

![Activate the subject whiteboard](/En/Images-New/uClass/quick-start-for-teachers/7.png)

## Step 5: Use the subject whiteboard

Open your personal space and select **[Whiteboard]** to open the subject whiteboard.

![Open the whiteboard in your personal space](/En/Images-New/uClass/quick-start-for-teachers/8.png)

![Use the subject whiteboard](/En/Images-New/uClass/quick-start-for-teachers/9.png)

## Step 6: In-class interaction

### 1. Enter the class session

In **[Classroom interaction]**, find the class session and select it to enter.

![Enter a class session from Classroom interaction](/En/Images-New/uClass/quick-start-for-teachers/10.png)

### 2. Conduct in-class interactions

Select classroom interactions as needed, including roll call, student selection, Buzzer, voting, discussion, awarding points, and photo upload.

![Conduct in-class interactions](/En/Images-New/uClass/quick-start-for-teachers/11.png)

### 3. Use classroom resources for teaching

![Use classroom resources for teaching](/En/Images-New/uClass/quick-start-for-teachers/12.png)
