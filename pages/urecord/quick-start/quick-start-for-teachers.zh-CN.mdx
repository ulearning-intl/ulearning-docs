# uRecord极速体验之教师

## 第一步：登录uRecord

### 打开网站

根据所在站点选择域名，站点如下：

（1）亚洲站（asia）：[https://www.ulearning.asia/ulearning/index.html#/i18n](https://www.ulearning.asia/ulearning/index.html#/i18n)

（2）拉美站（pro）：[https://www.ulearning.pro/ulearning/index.html#/i18n](https://www.ulearning.asia/ulearning/index.html#/i18n)

### 2.登录

支持两种登录方式，可以选择校园统一身份认证或直接输入账号登录（网站暂不支持注册，请联系管理员或平台客服）

![image](/Images-New/uRecord/quick-start/quick-start-for-teachers/1.png)

## 第二步：课堂回放管理

### 1.查看我的课程

录播系统会按照课表进行自动录制，录制的课堂回放会同步到资源平台，教师登录后，即可查看自己的课程和课堂回放。

![image.png](/Images-New/uRecord/quick-start/quick-start-for-teachers/2.png)

### 2.查看回放视频

视频播放器会同时显示三路视频，教师、学生以及课件的画面；鼠标悬浮在视频上方时，右上角会显示操作图标，可以放大或者关闭某一路视频。

![image.png](/Images-New/uRecord/quick-start/quick-start-for-teachers/3.png)

### 3.查看AI分析

根据大模型语义分析，可以概括出本节课老师讲解的主要内容，并提取关键词，方便学生快速了解回顾本节课内容。

![image.png](/Images-New/uRecord/quick-start/quick-start-for-teachers/4.png)

## 第三步：查看个人督导听课任务

### 做督导任务

【我的任务】展示的都是督导评课的任务。“线上听课”可以远程线上评课，可以直接通过直播/录播听课评议；“线下听课”需要到教室中线下完成听课，线上填写评议。

![image.png](/Images-New/uRecord/quick-start/quick-start-for-teachers/5.png)

### 2.查看被评记录

教师通过【被评记录】，可按学期和评价类型一站式查阅督导、同行及学生等多方视角的听课反馈与得分情况，助力教师自我诊断与专业成长。

点击【查看详情】查看评价内容：

![image.png](/Images-New/uRecord/quick-start/quick-start-for-teachers/6.png)
